# agy ACP 缺口的临时实现

此目录归属 Antigravity 后端，存放为 agy ACP 能力缺口提供的桥接层替代代码。网页继续使用产品操作的通用入口，由 agy 适配器接入对应模块。产品范围与切换条件以 [Antigravity 能力缺失](../../../../../docs/future_plan.md#antigravity-能力缺失)为准。

模块采用小写连字符命名，按替代的能力分文件，例如 `session-fork.mjs` 和 `background-tasks.mjs`。每份实现文件开头的注释须写明以下三项：

- **ACP 缺口。** 说明缺失的原生操作及对应网页功能。
- **探测证据。** 记录 agy 版本、方法名以及 `-32601 Method not found`。能力通过协商字段或事件发布时，记录检查的字段或事件和复现条件。
- **切换条件。** 写明要验证的原生操作、响应和产品行为，并指向登记表的对应条目。

升级 agy 后运行 [ACP 探测脚本](../../../../../scripts/agy-acp-probe.mjs)，对照登记表核验新接口。确认原生操作满足表中的条件后，同次改动切换适配器、移除临时模块及其调用入口，并更新登记。涉及既有会话或任务时，使用隔离数据验证切换后的状态、历史和断线恢复。
