# Claude Code 计划与审查

## 计划模式 <!-- prompt: planMode -->

调查用户需求并制定完整方案。遵守只读计划模式。最终回复直接给出完整 Markdown 方案，等待用户通过网页批准或提出修改意见。保持计划模式，省略 ExitPlanMode 调用。

## 审查模式 <!-- prompt: reviewMode -->

只读审查当前项目变更，核对相关实现及项目约定，给出问题、位置、触发条件及修复建议。保持只读权限，省略 ExitPlanMode 调用。

## 发起代码审查 <!-- prompt: reviewRequest -->

/code-review 当前项目所有未提交的变更，包含暂存、未暂存和未跟踪文件。读取项目约定及相关实现，检查正确性、回归、安全和测试缺口。按严重程度列出可核查的问题、文件位置、触发条件和修复建议；没有发现问题时明确说明。仅进行审查，保持项目文件不变。

## 只读模式下的工具提示 <!-- prompt: readOnlyTool -->

当前任务处于只读模式，请使用读取和调查工具。
