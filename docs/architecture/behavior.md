# 功能与状态契约

本文记录跨模块协作必须保持的产品行为，用于实现评审和回归选择。模块关系见[架构设计](../architecture.md)，测试运行方法见[开发者指南](../development.md)。每项契约同时约束实时通知、历史恢复与页面重新连接；修改行为时同步检查它的所有入口。

## 双后端与供应商

设置的分区标题保持清晰，模型与服务配置始终展开，供应商直接列在所属后端下，省去重复标题和折叠入口。网页登录状态与退出按钮同行，窄屏允许换行。键盘操作保留在各自入口，设置省去常驻快捷键说明。

默认供应商在自定义项之前，按服务端目录显示品牌图标、身份、状态及操作。具体模型由模型菜单和编辑表单展示。默认供应商只开放 API Key，地址、协议、模型及能力使用服务端官方定义，旧配置的自定义参数自动归一化。空 Key 清除凭据并停用，非空 Key 启用，模型目录和运行时使用同一启用状态。自定义供应商沿用原有凭据语义。

自定义供应商的名称与 API 协议同行，API 地址与 API Key 同行。同列控件左边缘对齐，协议下拉延伸至表单右边缘，清除凭据入口位于 Key 输入框右侧。协议选项为“Message API”和“Message API （兼容）”，分别采用原生请求及系统消息布局转换；新增供应商及预置 DeepSeek 默认使用原生 Message API。

自定义供应商编辑表单通过显示原始模型 ID 的下拉菜单选择要配置的模型，表单按模型 ID 保存未提交草稿。连接和模型设置共用左侧标签列，显示别名与紧凑的上下文容量输入相邻，整行与模型下拉框共用输入起点和右边缘。容量居中，默认填写完整数字，点击小写 k 按钮切换单位，按钮显示选中状态并提供悬停提示。单位切换按 1k 等于 1024 tokens 转换并保留有效容量，保存时提交正整数 tokens，重新编辑显示精确容量，留空使用自动容量。任一模型的容量无效时，表单标明对应模型并保留草稿。思考强度轴的档位可独立点选或通过键盘勾选。别名按供应商及模型 ID 保存，清空使用原名称；保存成功后更新聊天模型菜单，取消编辑或保存失败时分别放弃或保留表单草稿。模型请求与历史记录继续使用原始模型 ID。

网页安装与启动支持尚未安装任何原生 CLI 的环境，登录后可在设置中安装所需后端。新建 Codex 用户服务通过已有后端启动脚本运行，缺少 CLI 时由 systemd 重试；安装完成后启动原生 app-server，桥接按原连接流程恢复就绪状态。

CLI 一键安装以当前平台原生组件完整下载为前提，完成后安装同一清单版本并校验实际 CLI。下载失败保留已有安装及版本，提供重试。CLI 检测与安装失败在设置中显示简短提示，原始错误保留在默认收起的详情中，展开后限制高度并允许长路径换行。操作成功后清理对应错误和诊断。

供应商操作在列表行尾右对齐，自定义供应商的编辑与删除相邻。编辑表单在所属供应商下方展开，新增表单从列表末尾的添加入口展开。保存和删除进行期间暂停供应商列表操作。删除成功后刷新供应商及模型目录并关闭该供应商的编辑表单，失败保留列表及编辑内容并显示错误。默认供应商通过清空 API Key 停用。

项目模型偏好在所属后端离线时仍可读取和保存；保存成功向所有页面广播所属后端的完整项目偏好，保存失败保留原数据并允许重试。依赖执行状态的目录创建、单文件撤销、整理核对和子代理消息读取在后端就绪后执行。整理占用期间，两端统一暂停开始轮次、补充输入、审查、历史回退和再次整理，历史与项目偏好保持可读。

新对话的项目模型偏好须在当前供应商的模型目录中匹配后恢复；失效偏好依次采用目录内的配置默认模型、原生默认模型及首项，空目录清空模型和思考强度。历史对话保留原模型身份，目录缺失时在模型菜单中显示禁用的不可用状态，用户可主动选择有效模型。

侧栏底部跟随当前对话所属后端，新对话跟随所选模型后端。Codex 显示账户用户名、套餐或 Codex；Claude Code 原生账户显示实际身份及可取得的额度窗口，配置外部供应商时显示供应商名称及外部计费状态。读取失败保留已有数据并提供重试，未取得外部余额时保留实际状态。连接状态同时检查网页连接和所属后端就绪状态。

对话顶部与侧栏各对话仅用图标区分后端，Codex 使用 OpenAI 标识，Claude Code 使用 Claude 官方标识，图标省去名称、悬停提示和附加标签；标识在单后端、断线和刷新后继续显示，依据对话归属确定。页面提供固定的 Codex 和 Claude Code 两个后端，模型菜单以“供应商 · 模型”区分选择。ChatGPT 模型沿用 Codex 原生配置；Claude Code 供应商在设置中配置地址、凭据和模型，多个供应商共用同一个 Claude Code 后端。设置保存和接口校验均约束为两个后端。标题前的复选框即时保存启停；停用后端的对话立即从侧栏移除，正在查看的所属对话回到新对话，重新启用后恢复显示，无需刷新页面。CLI 安装位置及原生目录自动取得。设置自动展示安装状态、当前 CLI 版本与 npm 官方最新版本，未安装提供“一键安装”，已安装提供“一键更新”。服务器持有安装任务，关闭设置或重连后继续展示结果；忙时拒绝更新，失败保留实际错误及重试入口。版本由桥接服务启动时及此后每小时自动检测并广播，网页在各自后端内展示缓存结果，省去手动检测入口和“已是最新”文案。版本查询失败保留已取得的版本并标明查询错误。

新对话选择模型后自动确定后端；已有 Claude 对话空闲时切换供应商和模型，下一轮恢复同一个原生会话。用户消息、助手正文及工具记录沿用原生历史。原生 `origin.kind=task-notification`、`isSynthetic` 及 `isVisibleInTranscriptOnly` 标记的记录保持内部归属；SDK 实时帧按本轮实际提交的输入 UUID 确认用户归属，原生历史中仅继承 `entrypoint=sdk-ts` 与 `promptId`、缺少提交来源与轮次归属的附加记录保持内部归属。工具结果仍更新对应工具；用户主动输入相同文字继续显示。内部记录不创建用户轮次或推进活动时间，已保存的自动唤醒锚点仍用于恢复独立轮次。子代理转发帧在处理主对话生命周期和用量前隔离。运行中的轮次沿用启动配置。同供应商的模型选择仍可为下一轮调整，切换模型保留已有技能与命令目录；跨供应商切换在空闲时进行。新草稿初始化先恢复供应商，再读取其模型、账户及项目偏好。重新打开对话以已保存的供应商与模型恢复，供应商间重复的模型名称按供应商标识区分。已有对话的模型菜单显示所属后端的模型；跨运行时交接按独立需求设计。

## 对话、项目与历史

输入区 `@` 提供文件、目录、技能和同后端其他会话。本机工作区的文件和目录由统一搜索提供，目录自身名称通过前缀或跳字命中时同样优先于文件。各类型优先显示可见路径，再比较路径和名称的精确度、前缀及模糊匹配质量，较浅路径优先用于区分相同名称。显式输入隐藏路径时按匹配质量排序。跨主机 Codex 从远端接收原生候选，网页提升直接命中的目录与文件并保留其余原生次序。 搜索失败显示实际错误，修改关键词后可重试。

`@` 查询包含路径分隔符时仅提供文件和目录，连续匹配的层级和相邻父目录命中提高结果优先级。目录缩写可以跨越中间层，最后一段匹配候选自身名称。绝对路径和以 `./` 或 `../` 开头的路径查询从工作区内的明确位置匹配。空查询和以 `/` 结尾的查询浏览指定目录，按类型和名称排序。独立的 `/` 查询提供快捷命令和技能。技能候选支持名称、显示名和技能目录的大小写无关模糊匹配，允许按字符顺序输入缩写与跳字；精确、前缀、连续和紧凑跳字匹配依次优先，描述关键词作为低优先级补充。 停用技能退出候选，会话候选排除当前对话。

Tab 将当前候选补全为可继续编辑的查询文本并保持建议打开，文件与目录补全完整路径，支持继续输入 `/` 逐级查询；Enter 或点击确认后以独立的行内引用显示，文件按扩展名区分图标，目录、技能与会话使用对应图标；菜单关闭，光标移到引用后的空格。引用节点支持两侧输入、整项删除、撤销、复制粘贴、切换与刷新草稿恢复，发送和消息编辑保持名称与目标。删除引用同时移除该项的提交数据；重复引用保留正文位置，原生元数据按目标去重。Codex 使用原生技能与 thread:// 会话引用，通过同后端只读 read_thread 工具按需读取已保存正文，Claude 技能使用原生命令，会话引用在发送时读取完整分页的用户和助手正文；读取失败保留完整草稿。代码与普通外部链接保留原语义。

### 侧栏、项目和对话标题

宽屏侧栏按浏览器视口方向决定默认状态，竖向默认收起，横向默认展开。横竖方向的手动选择和窄屏抽屉的开合状态各自在当前页面内保留，跨越方向或布局断点时应用对应状态。手动收起后焦点回到顶部的侧栏入口，切换方向收起侧栏时，侧栏内的焦点也回到该入口。顶部和侧栏的对话操作菜单在按 Esc、点击菜单外或焦点移出时关闭。Esc 后焦点回到菜单入口，点击菜单外时继续执行所点击控件的操作。

侧栏将所有可见的活动轮次对话集中排列在置顶和项目文件夹上方，仅沿用会话行左侧的运行圆圈，省去分区标题和说明。顶部快捷入口沿用对话排序，同时保留原项目或置顶列表中的会话。成功完成且带未读绿点的会话继续保留顶部快捷入口，当前选中的顶部会话在阅读清除绿点或轮次结束后继续保留，切换会话或新建对话后再移除；其他已结束会话沿用未读状态保留顶部入口。原项目归属、置顶偏好和文件夹收放状态保持不变。活动状态沿用实时轮次事件与重连快照。 未读绿点只代表当前页面观察到轮次成功结束且未阅读。历史成功加载且页面可见时视为已读，读取失败保留提示。提示仅保存于当前页面，刷新清除，新轮次清除旧提示。置顶对话优先显示运行或未读标记，其余时间保留置顶图标。各状态标记位于标题左侧，标题保持一致起点。

侧栏、搜索结果和标题菜单使用同一排序。进行中的对话置前，按发起当前轮次的消息时间倒序，其余对话按最近有效结束时间倒序。缺少对应时间时沿用创建时间，侧栏按排序依据显示时间。打开、重命名和切换保留排序时间，新一轮开始或结束立即重排。完整分页历史补齐时保留较新的实时开始或结束时间。两个后端独立读取，任一后端失败时保留已显示且符合当前归档和搜索范围的记录，其余后端继续更新；侧栏及搜索显示所属后端的实际错误并提供重试。相同查询保留此前已确认的正文匹配记录，修改查询及卸载后忽略旧请求结果。

项目按固定状态分组，固定项目始终位于未固定项目之前，空项目及仅含置顶对话的项目同样遵循此规则，“未分类”始终位于末尾。同类项目的顺序使用页面内快照，归档、恢复和实时活动保留快照；固定与取消固定立即按新状态重新分组，各组内部沿用快照顺序。手动添加或固定的项目跨刷新保存。固定文件夹默认展开，其余默认折叠，每组先显示最新五条；“查看更多”覆盖后端全部分页。“未分类”保留独立归属，新建时按首次发送流程准备工作目录，已有目录可以沿用。 首次使用完整未归档分页结果，按组内最近有效结束时间排序。新增项目插入同组首位，已有空项目留在原位置，刷新后重新确定顺序。侧栏置顶区独立展示。

对话时间靠标题行最右侧显示；支持悬浮的设备上，归档（归档列表中为恢复）和三点管理按钮默认隐藏，鼠标悬浮当前标题行、键盘聚焦或菜单展开时，在时间所在位置覆盖显示，背景沿用当前行颜色。标题和图标按钮自身在悬浮时保持透明，由整行统一显示悬浮或选中背景。按钮使用叠加布局，显隐时保持标题及时间位置稳定；无悬浮能力的触屏设备保留直接操作入口。

侧栏对话标题在鼠标悬停或键盘聚焦时使用页面内浮层完整展示，长标题自动换行，浮层适配深浅主题并避开列表滚动裁切；移开、失焦、点击、Esc、滚动或窗口变化时清理，归档与管理按钮保留各自操作。

收到外部归档通知，或对话请求返回与请求中的对话 ID 对应的已归档状态时，自动同步归档并刷新列表；正在查看或加载的聊天回到新建界面，保留本地未发送草稿与项目顺序。同步采用后端已有归档结果，迟到响应继续按所属聊天隔离，恢复通知同步刷新列表。

客户端无项目对话仅在桌面状态标记与自动目录记录匹配当前 `cwd` 时合并到“未分类”；CLI 或外部端有明确目录的对话继续按目录分组。已有项目归属和网页显式添加的项目优先，缺少目录的对话归入“未分类”。桌面状态从 `CODEX_HOME` 或当前用户配置目录只读取得，随列表加载刷新。

“未分类”在空列表中也保留新建入口。网页无项目对话首次发送时在 `CLAUDEX_WEB_CONFIG_DIR/workspaces` 分配独立目录，并通过后端持久保存的 `threadSource` 与自动目录共同恢复分类；列表缺少来源标记时，仅在创建者为 `claudex_web` 且当前目录为根下直接生成的 `chat-XXXXXX` 目录时补充识别，已有项目归属继续优先。选择具体文件夹后按目录创建。分组名称与执行目录分别维护，确保发送、重新加载、失败重试和全局新建入口保持正确归属。

侧栏对话可拖到项目文件夹或“未分类”标题，悬停高亮，保存成功后展开目标并显示对话。移入文件夹为后续轮次选用目标目录，移到未分类保留有效工作目录；运行中的轮次继续完成，后续恢复和新轮次应用迁移结果。归属保存在服务端，刷新、重新连接、归档恢复及其他页面均沿用；保存失败保留原归属、草稿及附件，并提供错误提示。置顶对话移入文件夹后取消置顶。每个网页项目对应一个文件夹，原生历史通过所属后端读取。 归属及执行目录原子保存，按完整对话标识和递增版本隔离迟到结果。

顶部目录菜单沿用侧栏的分组顺序，仅列出当前对话列表中有记录的文件夹和“未分类”，置顶对话计入所属分组。选中其他分组直接打开排序首位的对话。标题菜单列出当前分组的对话，进行中条目沿用侧栏的转圈图标。打开对话恢复所属草稿。两个菜单标记当前项，选择当前项关闭菜单，支持方向键、Tab 和 Esc，窄屏保留两个入口。输入区底部的文件夹入口用于浏览和选取工作目录。

主对话与子代理使用 `domain/thread-history.js` 的完整历史读取流程。仅在 `thread/items/list` 明确不受支持时回退到 `thread/turns/list` 的完整消息分页（`itemsView: full`）。写入被其他客户端占用时继续提供已保存历史；其他读取错误保留实际错误和重试入口。

分支通过 `thread-catalog.js` 的统一动作创建。并行读取所属后端的未归档与已归档家族元数据，按真实 `forkedFromId` 关系生成数字后缀，标题最多 60 字符。旧网页的 ` (分支)` 后缀仅在父子标题匹配时兼容，手动改名与独立同名对话保持各自标题。创建及命名确认后打开分支，历史从最近一页开始加载，侧栏随后补齐。Codex 新分支的输入状态取自原生创建结果。用户在创建期间切换对话时，分支加入列表并保留当前选择。侧栏菜单、回复操作与 `/fork` 共用流程。归档、删除和标题通知同时更新当前对话与列表，旧列表或打开响应保留通知中更新的结果。

创建对话分支时显式传递来源对话的模型和思考强度。当前对话采用创建动作开始时的输入区选择，侧栏其他对话通过原生读取结果取得配置；分支恢复继续采用后端保存结果。回归覆盖全局默认模型与来源不同及非当前对话分支。

Codex 首轮发送后，桥接使用独立连接及临时会话生成简短标题；写入前重新读取目标记录。手动改名、归档、删除及断线取消旧生成任务，生成失败可在后续打开或发送时重试。标题生成的消息和订阅与用户对话隔离。Claude Code 对话沿用其原生标题与网页保存的用户名称。 打开无标题历史时补齐，使用 `thread/name/set` 保存，已有名称及手动重命名优先。

Claude Code 的模型会话和后台任务由独立执行服务持有。网页关闭、桥接正常重启或异常退出后继续执行，恢复连接时读取同一服务的活动轮次、执行状态及待答提问；同一输入保持一次原生提交。停止或替换执行服务按真实在途请求、活动轮次、整理、队列、提问及后台任务检查占用，忙时保留服务并返回实际状态。代码与运行配置变化在忙时标记待更新，空闲后切换；旧网页桥接重新连接保持较新的执行代际。无活动任务、目标或后台任务的 SDK 会话空闲 5 分钟后释放，再次发送从原生历史恢复。

自动更新遇到并发请求时，设置页继续显示当前 Claude Code 连接状态，现有请求可继续完成。用户主动停用、更新 CLI 或保存需要停止执行服务的配置时，操作遇到任务占用会返回失败原因，并保留现有配置供重试。

## 输入、草稿与执行

### 连接与写入

Codex 对话恢复遇到原生明确报告的目标线程关闭中状态时，页面继续显示检查状态并保留历史、草稿及附件。成功后自动恢复输入，失败、超时及断线沿用原有状态和重试入口。桥接遵循 [Codex 订阅与恢复契约](backends.md#codex-订阅与恢复)。

连接初始化仅恢复开始时选中的对话；列表或配置请求迟到时，保留期间的新建、发送与切换操作。重连按连接实例隔离事件和初始化结果，已替换连接的消息与关闭事件不得改变当前连接状态；发送前核对实际 WebSocket 状态。新对话首次发送回归使用纯文字，覆盖初始化列表晚于提交的时序。按故障浏览器实例核查连接与本地状态，设备类别只作为环境信息。后端断连日志记录关闭码、关闭原因和待处理请求方法。

已显示的当前对话在重连时后台同步历史和写入状态，保留消息、阅读位置、工作过程展开状态、输入框、草稿与附件。后台检查期间允许编辑并暂停发送，成功后恢复发送；历史补齐断线期间的变化，读取期间新到的实时记录继续优先。旧连接及旧恢复任务的迟到结果按连接、初始化版本和当前对话隔离。前后台切换回归使用隔离数据，覆盖连接持续正常、实际断线、同步期间编辑、历史失败、再次断线和切换对话。

对话打开时先独立读取并显示历史，再检查写入权、恢复设置与实时轮次。检查期间暂停输入；写入占用或恢复失败时在发送框位置显示状态区与重试按钮，保留历史、草稿和附件。重试重新检查当前对话，成功后恢复发送框，由用户继续发送；独立进程保存的进行中轮次保持为历史展示，消息区域省去重复的占用提示。发送入口统一检查写入状态，迟到结果受当前对话与检查请求约束。新建空对话保留至首次成功提交或页面关闭，确保尚未落盘的对话可以发送和重试。已有记录的网页对话空闲且相关请求结束后释放订阅，页面保持打开时也释放；发送、整理上下文、审查在转发前恢复已释放的对话，并在恢复到提交之间持续保护订阅。同一对话的并发写入共用恢复请求，运行中的轮次完成后再释放。Codex 新分支直接采用原生创建结果初始化输入，目标读取使用原生已保存状态；新轮次按实际订阅恢复写入。其他客户端的写入锁按所属后端的实际能力处理。后端启动使用 `-c thread_unload_delay_secs=0`，使无订阅的空闲对话及时卸载并释放写入占用。保留已有后端服务配置时，检查这一启动参数。

### 正文、附件与运行参数

切换对话后，目标对话的输入框可编辑时自动聚焦，光标落在恢复的草稿末尾。富文本编辑器加载期间先聚焦临时文本框，加载完成时交接当前焦点和选区。连续切换时，焦点跟随最终打开的对话。

图片及其他附件随所属对话在当前页面内保留，切换到其他对话再返回时恢复原附件列表；尚未首次发送的新对话同样恢复。移除附件后保持移除，首次发送创建实际对话时迁移附件草稿。一次选择多个文件时，在文件选择框重置前取得全部文件，并将每个文件的读取绑定到原草稿。异步文件读取完成后更新原草稿，发送失败保留附件供重试，发送成功仅清理已提交附件，保留等待期间新增的附件。

上传附件保留原始字节与文件元数据，草稿仍归所属对话。图片使用大图预览，UTF-8 文本、音视频和 PDF 按格式展示；压缩包、Office 及其他二进制文件提供信息与原文件下载。非图片附件发送前由公共工作区服务写入网页配置目录下的受限附件目录，再以本机文件引用提交给所属后端；上传失败保留草稿，重试复用已上传路径。预览对象 URL 由窗口持有并在关闭时释放。

正文输入即时更新独立草稿订阅，按对话持久保存。正文编辑区默认容纳两行，随正文、代码及公式的实际高度自动增高，到达可用空间上限后在内部滚动。上边缘公共手柄支持向上拖动增高、方向键调节及双击或 Home 恢复自动高度，手动高度按可用空间比例保存并跨刷新恢复；展开入口打开居中的编辑窗口，复用同一文档实例和撤销栈；底部保留放大前的正文预览、输入框轮廓、工具栏及原有尺寸，页面布局与阅读位置保持连续，背景预览通过隔离节点提供只读展示；通过关闭按钮、Esc 或收起入口返回紧凑输入，保留草稿、选区及原高度选择。编辑窗口复用公共窗口手柄，支持拖动、键盘调节、复位及尺寸偏好恢复。窄屏、缩放及附件变化重新限制高度，发送工具栏保持可见。普通正文和同级列表完整显示，光标与选区由浏览器原生维护；滚动后继续输入时定位到真实编辑位置。加载期间的文本、焦点及完整选区交接给文档编辑器，对话切换后旧实例只清理自己的输入适配。Ctrl+Enter 与发送按钮走同一提交入口，Enter 保留换行；组合输入确认保持正常编辑。输入期间共享状态快照稳定，长历史和文件面板保持渲染隔离。

正文使用 Markdown 富文本编辑，支持 CommonMark、GFM（表格、任务列表、删除线、自动链接及脚注）、数学公式。Mermaid 以普通代码块输入，HTML 保留源码。用户直接编辑排版后的正文及表格单元格，选区格式工具提供常用操作；持久化和发送使用 Markdown。纯文本 Markdown 粘贴直接插入原生文档节点，保留代码语言、公式及表格，选区替换和光标落点遵循粘贴位置；块后保留正文续写位置，一次撤销恢复整次粘贴。富文本副本保留其文档结构，代码内部保留字面内容。编辑器实例及撤销栈归当前对话的输入组件所有，切换对话时销毁；异步初始化及迟到输入回调按挂载生命周期隔离。输入后立即发送读取即时草稿，文件引用和快捷命令继续使用统一入口。编辑器和运行时资源从本站加载，加载期间保留可编辑的 Markdown 文本框。 编辑器、语言支持、样式和公式字体随发行包交付。

提交快照包含正文、附件、文件引用和全部批注。失败保留可重试内容，成功只清理与已发送快照一致的草稿；请求等待期间的新输入或批注继续保留。运行中补充使用当前轮次通道，新的轮次带上当前模型、有效思考强度、速度模式和统一执行策略。

新对话的模型和思考强度按项目保存。已有对话打开、刷新及重连时，从后端对话读取与恢复结果取得该对话的模型和思考强度；项目默认选择仅用于新建对话，恢复请求期间的手动调整继续保留。服务端项目设置是跨浏览器恢复来源，本地缓存和待写入选择用于即时交互及失败重试；迁移只补齐服务端缺失值。同项目新建沿用当前有效选择，跨项目恢复目标选择。模型切换保持支持的强度，不支持时由领域规则选择最近的可用档位；迟到恢复保留期间的手动调整。

选择模型时，最接近的强度档位有两个时取较低档。模型与强度保存到 `CLAUDEX_WEB_CONFIG_DIR/project-models.json`，未分类使用独立偏好。服务器串行原子保存并广播，失败保留待保存选择并在重连后重试。为新对话选择工作目录保持草稿和附件。

速度模式独立于模型和思考强度，在输入框和模型弹窗使用闪电图标点击切换标准与 Fast，绿色实心表示加速，灰色描边表示标准，悬浮提示与 `aria-pressed` 报告状态。首次加载读取 Codex 配置，恢复对话和设置通知读取实际服务档位；新建与下一轮发送显式携带 `serviceTier`，标准使用 `null` 清除已有档位。运行中补充沿用当前轮次速度，切换模型时仅保留其支持的档位，重连与失败重试保留已选标准速度。

上下文用量仅通过常显文本展示最近一轮 tokens、上下文窗口容量和使用百分比，窄屏下保留显示并自动换行；尚无用量数据时显示发送快捷键。

输入区模型入口按当前选项显示完整的供应商与模型名称，宽度随内容和工具栏可用空间调整，超长名称允许换行。原生下拉选择、键盘操作和禁用状态保持一致。可用宽度很窄时，发送区单独成行，为模型名称和其他工具保留整行宽度，正文两行及发送与停止按钮保持可见。

思考强度通过带离散档位圆点的胶囊滑块调整，标题旁显示当前档位，滑块下方省去重复的档位文字。输入框的紧凑入口展开独立面板，模型弹窗复用同一控件；拖动、点击轨道和方向键使用后端返回的支持档位。模型选择和速度模式分别使用各自入口。 工具栏保留附件、模型、思考强度、速度及计划模式。窄屏继续提供强度、速度和计划入口，技能通过侧栏或快捷命令进入。

执行策略统一为完全访问，界面省去权限选择。快捷命令注册与参数解析集中在 `features/commands`，菜单、按钮和键盘使用同一入口。`/` 在输入开头、空格及换行后提供命令与技能建议。中途确认网页命令时仅移除当前查询，保留前后正文及附件，执行失败恢复完整草稿；原生命令将已有正文作为参数提交，原生技能将命令放到正文前等待发送。开头命令继续读取后续参数。18 项网页通用命令保留统一用例，Claude Code 当前目录的原生附加命令由实际运行时目录提供。`/init` 保留并打开已有目录指令文件；`/goal` 使用实际目标接口，显式修改携带用户来源，目标及后台终端查询保留尚未发送的空对话；`/stop` 清理当前对话全部后台终端分页。Claude Code 每次提交按祖先到当前目录读取 AGENTS 项目指令，同目录优先 `AGENTS.override.md`，保留完整原文、路径与作用域；本轮快照替换此前快照，修改和删除在下一轮生效，原生 `CLAUDE.md` 持续适用。完整支持范围见[命令覆盖记录](../cli-command-coverage.md)。

所有公式使用 `$$公式$$`，同一行及换行输入统一生成当前段落内的行内公式，光标停在公式后并可继续正文。单美元符号作为普通文本。闭合前保留可编辑源码，公式可双击或通过键盘重新编辑，修改后以 `$$` 再次闭合。粘贴、草稿恢复和发送沿用同一双美元符号语法；代码块与行内代码保留美元符号源码。

Markdown 输入以逐字键入后自动排版为主要交互，选区格式工具用于补充操作。列表中的行内公式、标题、强调及代码围栏均支持连续输入；代码语言保留在围栏标记中，闭合围栏后回到正文。回归分别覆盖逐字键入、整段插入、粘贴和中文输入法提交，检查可见结果及发送的 Markdown。

链接末尾续写时使用普通正文格式，空格及后续文字保留在链接之外；链接内部继续支持编辑显示文字。粘贴网址、Markdown 链接和草稿恢复遵循同一边界。

在底部输入区或原位消息编辑框粘贴带代码编辑器语言信息的单行片段时，片段以行内代码插入当前段落，剪贴板末尾的单个换行按行结束符处理。前后正文及一次撤销的范围保持完整。多行片段保留原语言及代码围栏，粘贴网页行内代码保留其行内格式。

最近一轮的初始用户消息提供铅笔形“编辑上一条消息”入口；原消息位置切换为紧凑的 Markdown 编辑框，正文固定两行并通过内部滚动查看长内容；宽度最多为 42rem，窄屏内最多占消息区的 90%。背景、边框、阴影和聚焦边框与底部输入框共用规则，发送使用主操作配色，深色及跟随系统主题同步适配。支持取消、发送、Enter 换行与 Ctrl+Enter 提交。编辑正文、引用附件和批注由消息组件独立持有，底部草稿保持原值。运行中补充消息继续通过运行轮次发送，历史编辑针对完整轮次。

原位编辑框独立于底部输入区的高度偏好及调节手柄，打开、取消及重新打开均保持两行布局，保留 Markdown 文件引用的名称与目标。

编辑提交先读取完整分页核对最近消息及运行状态，通过 `thread/revert` 回退到原轮次之前；仅在该方法明确不支持时使用 `thread/rollback`。成功回退后清理已移除的历史、时间与差异，再提交新轮次，刷新以实际后端记录恢复。回退失败保留原历史，发送失败保留编辑框及输入，重试核对保留轮次并复用已成功的回退。取消已回退的失败编辑时读取实际历史。连接、写入检查、整理及运行状态限制提交，异步读取和回退响应按对话及打开版本隔离；回退使较早的历史分页请求失效。其他页面收到 `thread/reverted` 时重新恢复所属对话。

Claude Code 编辑及分支通过原生会话分支保存保留前缀，网页逻辑对话与保留轮次标识稳定，原生 UUID 和后台自动唤醒锚点随分支更新。保留的原生别名归属原逻辑对话，列表和删除恢复保持去重；发送失败后重试沿用已成功完成的历史回退。

## 批注、引用与提问

用户消息正文与助手正文共用 Markdown、GFM、公式及安全过滤渲染器，复制和编辑保留 Markdown 源码。引用仅在 Markdown 文本节点中转换，代码、链接和公式保持自身语义。

用户消息统一解析正文、文件引用及回复批注。显示、复制、编辑使用可读内容，提交保留所需引用协议。文件和目录以类型图标及蓝色链接呈现；点击目录定位到文件列表，点击文件在右侧打开。解析失败的普通内容保留原文。 键盘可激活引用，目录与文件沿用未保存确认和目标隔离。普通正文、损坏引用和旧网页或客户端上下文按各自兼容规则解读。

回复批注兼容桌面端的 `# Response annotations:` 与 `<response-annotations>` JSON 格式，保留原文、批注及可选来源位置。助手回复中的 `:codex-annotation{index="N"}` 显示为可展开的编号引用，按所属轮次和前置用户消息关联；代码及公式中的标记保留原文。批注入口仅随有效文字选区显示，同一条回复及同一对话的多条回复均可连续添加多个批注；编辑器在原文旁悬浮，采用客户端的单一圆角表面、无边框输入区、随内容增高和图标操作，原文通过所在位置、编号及无障碍描述关联；原文旁显示可重新编辑的编号，输入框汇总待发送批注并提供编辑和移除入口。添加、编辑、完成和关闭批注均只更新草稿；批注编辑器中 Enter 与对勾按钮均完成批注并返回主输入框，Shift+Enter 换行，输入法选词时的 Enter 保持输入；底部发送按钮或 Ctrl+Enter 将当前对话的全部批注、主输入框正文及附件一次提交，空正文时也可发送批注。草稿按对话持久保存，刷新和切换恢复，兼容迁移旧的按消息保存的草稿；失败保留全部输入，成功仅清理与提交快照一致的内容，保留等待期间新增或修改的草稿。运行中使用普通补充通道，写入检查和上下文整理占用统一约束提交；使用隔离数据验证批量发送、悬浮位置、缩放及窄屏布局。

批注浮窗按实际 CSS 可用宽度使用统一的换行判据，验证逐字输入到换行，以及删除后恢复单行。

### 提问收纳

待答请求按请求 ID 去重并按对话、轮次同步，重连从快照恢复。待答提问在所属工作过程下方独立展开，提交成功或请求结束后收入过程，每条结束记录提供独立的折叠入口并默认收起；展开工作过程后仅显示提问摘要，点击该摘要才展开题目、全部选项及可取得的实际回答，相关说明正文一同收纳，私密字段仅显示提交状态。题干、选项和回答输入共用聊天正文的字号与行高，提问摘要与工具记录使用一致字号和行高，辅助说明保持一致行高；提问卡片仅显示标题、题目、选项、回答框和提交按钮，省去辅助说明、重复字段标签及快捷键提示；失败在提交按钮中提供重试，具体错误通过按钮提示取得。回答框默认单行高度并保留公共调节手柄，Enter 提交整份回答，Shift+Enter 换行，输入法选字期间保留原生行为；段落与控件使用紧凑间距，选项框使用紧凑内边距与 3px 纵向间隔。已答提问收起行直接复用工具记录的行高、上下间距和图文间距，按工具行直接排列，相关内容展开后缩进展示；窄屏沿用相同布局。同步提问通过 `item/tool/requestUserInput` 按请求 ID 回传，当前页面保留结束记录；异步提问从 `agentMessage.questions` 展示并通过普通用户消息回答，回答消息与原问题一同收纳，历史读取后恢复相同布局。空正文和后续助手进度均保留问题卡片，多批提问分别保留待答状态；一条回答只归属一批匹配的问题，普通补充保留为独立消息。发送失败保留卡片和已填内容，成功提交异步回答后立即收纳，保留消息草稿与附件，任务运行时补充到当前轮次，空闲时开启新轮次。过程区域按轮次保持稳定标识，提问出现、回答及后续进度均保留展开状态。

异步未答提问随所属轮次完成、失败或中断收入工作过程，结束状态由轮次记录、分页恢复的状态或该轮明确的最终回答确认，按轮次隔离。结束记录默认折叠并显示“提问已结束”，保留题目、选项和相关正文；展开后通过“补充回答”恢复填写入口。页面内按对话及消息保留未提交的填写内容，收纳后继续可用，成功发送后清除。回归覆盖实时结束、历史恢复、其他轮次继续运行、原过程展开状态以及补充回答的发送和草稿保留。

Claude Code 的完整 assistant 消息与流式结束原因分别到达时，按照真实 `message_delta.stop_reason` 确认最终回答或计划，过程文字继续收入工作过程。刷新按相同消息标识恢复已确认的展示类型。供应商 API 错误归入失败轮次和错误提示，公开提示与诊断详情分开，错误正文保持在诊断详情中。

## 整理上下文

整理使用独立的异步任务状态。浏览器在发送前设置占用并保存恢复记录，桥接在提交到轮次结束之间保留订阅。空确认只代表提交成功；实际成功、失败或中断由对应轮次通知或完整历史核对确定。

```mermaid
flowchart LR
  A[提交并持久化恢复线索] --> B[等待开始或结果]
  B --> C[运行中]
  C --> D[完成、失败或中断]
  B --> D
  B --> E[断线后待核对]
  C --> E
  E -->|分页核对实际轮次| C
  E -->|已结束| D
  D --> F[清理恢复记录]
```

整理占用同时约束发送按钮、Ctrl+Enter、运行中补充、重复整理、审查和桥接请求。正文及附件仍可编辑。刷新、重连、回到前台和“检查状态”核对实际记录，旧桥接缺少专用接口时使用已有历史接口。新轮次、无关自动整理及迟到响应按任务标识隔离。

手动整理期间由输入框上方的状态栏统一显示进度、耗时与恢复操作，聊天区隐藏通用工作提示及同一整理轮次的整理活动，保留其他历史和活动。整理结束后，整理记录继续按工作过程规则展示；自动整理沿用原有活动展示。

整理完成提示在关闭、离开该对话或提交有效新消息时收起；空消息保留提示。浏览器重新打开及重连快照只恢复进行中的整理，已结束结果仅更新页面已跟踪的同一任务，已收起提示保持关闭；浏览器离线期间结束的未完成任务仍显示核对后的结果。失败保留待发送内容，其他对话的完成提示保持独立。

## 计划模式

计划模式用于调查需求和制定方案。后端的 `plan` 消息作为独立方案卡片显示部分正文预览，底部渐隐并提供“展开计划”；展开后可从顶部收起，批准与修改按钮保持在预览区外，`item/plan/delta` 追加正文，完成记录替换同一消息；主对话和子代理只读历史采用相同排版。执行工具的 `turn/plan/updated` 步骤列表继续显示为执行进度。

最新方案所属轮次成功结束、且后续尚无用户消息时，提供“批准并执行”和“修改计划”。批准携带完整方案，通过 `turn/start` 显式选择 `default` 模式，确认成功后更新原对话的模式；失败保留原方案及重试入口。修改入口选择计划模式并聚焦原输入框，保留草稿，由用户提交修改意见。批准消息显示为简洁的操作结果，传输与历史保留完整计划。

模式按对话保存在浏览器中，刷新和切换恢复，新建对话使用默认模式。连接、写入检查、整理和消息提交期间统一限制批准，运行期间等待轮次结果。重复点击共用发送占用，提交前重新核对当前对话及方案；发送后的迟到结果按原对话保存模式，底部草稿、附件和其他对话选择继续保留。刷新后从完整历史和轮次状态重新确定批准资格，已有后续用户消息的方案保持为历史展示。

## 目标交互

`/goal` 进入主输入框的目标输入状态，并切换为执行模式；退出目标输入保留正文和附件。提交目标使用 `thread/goal/set`，已有目标先显示替换确认。附件先写入受限附件目录，再将本机文件引用纳入目标。目标摘要常驻输入区上方，按原生状态展示追踪、暂停、阻塞、用量限制、预算限制及完成，提供暂停、恢复、编辑与清除操作。刷新、重连与切换对话重新读取所属目标，实时通知优先于迟到响应。

Codex 目标自动续跑期间，桥接在相邻原生轮次之间保留订阅。原生后端继续处理已接收的中途消息，并将这些输入纳入后续模型请求。目标停止后依照原生轮次状态释放空闲订阅。

编辑在右侧详情完成，标题与关闭入口同行，紧凑工具栏集中展示更新时间、还原图标和保存按钮，正文占满中间可用区域。Token 预算默认收起于底部辅助区域，展开后编辑。支持 Markdown、还原与 Ctrl+Enter 保存；编辑草稿按对话保存，保存失败保留内容。保存正文沿用客户端激活目标的语义。目标操作按对话串行，断线、整理及提交期间暂停写入；预算及完成判断由所属原生后端维护。

## 消息展示与导航

### 工作过程和工具内容

Claude 原生思考按所属 API 消息的内容块顺序保留独立标识，流式、完整消息与历史读取使用相同标识，正文到达时保留已有思考。完整思考以独立标题和可展开正文呈现，单段长文本与多段正文均保留；原生摘要继续按其标题与正文展示。首个思考增量立即归属所属轮次，主对话及子代理采用一致的合并和恢复规则。

工作过程标题在所属轮次运行时每秒更新已用时，完成、失败或中断后固定显示总耗时，展开与折叠均保留显示。计时按对话和轮次隔离，沿用后端开始、结束时间和毫秒耗时；历史恢复与切换对话继续使用原记录，已有轮次列表请求同时恢复各轮计时。活动轮次的用户及工具记录时间保持为消息时间，结束时间只在轮次结束后确定；活动计时始终从开始时间持续增长。缺少时间记录的历史省略耗时，轮次结束或组件卸载后清理计时器。

命令记录与实时提示共用本地中文操作描述，操作名称使用简洁动词，涵盖技能阅读、文件读取、搜索、Git 检查、项目测试与构建及系统查询；技能阅读标题仅显示技能名称和必要行范围。组合命令保留顺序、条件与管道关系。未知片段保留原文；重定向、子 shell、命令替换和复杂控制流整体保留原文。展开详情始终展示原始命令、输出、退出码和工作目录。依据 rollout 扩充规则时仅提取命令类别与频次，测试使用独立构造的样例。

工具记录按操作与内容展示，图片查看及工具返回的图片在工作过程内直接显示缩略图并复用大图预览；网页搜索显示全部查询词，搜索结果仅显示标题链接，无标题时显示网址，省去摘要、类型、domain、ref id 等程序字段；打开网页显示链接，页内查找显示文字及可取得的来源。MCP、动态工具与函数结果按文字、图片、音频、资源链接和可读字段呈现，JSON 文本先解析，省略空字段和内部元数据，保留实际错误及通用工具结果。历史、实时提示与子代理详情共用展示规则；命令详情继续保留原始命令与输出。新增工具类型时扩展内容展示，避免整条记录直接序列化为 JSON；回归使用隔离数据，覆盖图片自动显示、实时完成、手动折叠、失败、深浅主题和窄屏。

工作过程汇总位于本轮最后一条普通用户消息之后、待答提问和最终回答之前。新补充令汇总随之移动，保留展开状态。折叠且仍在生成时，标题旁显示最新有效活动；多段思考摘要预览最后一段，轮次结束后收起实时提示。

领域层按轮次组合消息与工作过程，用户提问和中途补充保留独立消息；同轮补充同时按原始消息顺序收入工作过程，摘要行直接显示消息正文，短消息完整可读，长消息省略并可展开正文与附件，实时预览继续显示最新工作活动；工作过程默认折叠，运行时展示最新有效活动，结束后固定耗时。Codex 的 `delivery: async` 中途回复始终收入同轮过程，即使阶段为 `final_answer`；异步投递保留待答提问，回复操作只归属真实最终回答。最终回答的复制及分支按钮位于本轮文件汇总之后，实时生成和历史恢复遵循相同顺序。

### 历史与导航

全部历史保持连续可滚动。打开对话和回到最新时定位到真实底部，包括消息底部留白；自动跟随期间，输入框恢复、图片、图表及容器变化继续贴底。上翻或目录跳转后保留阅读位置，切换对话清理监听和待处理帧。

主对话打开时，最近一页消息先显示，写入能力检查独立恢复输入，其余历史在后台自动读完并合并；完整轮次时间读取与消息读取并行。补齐较早记录时维持正在阅读的内容位置，实时修改优先于首屏及历史快照。后台分页失败保留已显示记录并提供重试；切换后停止继续分页并丢弃迟到结果。未改变的正文和批注复用 Markdown 解析，普通状态通知和滚动操作保持既有回复渲染结果。 首屏读取最近 100 条消息。仍有历史且首屏仅来自同一轮时，后续每页读取一个完整轮次；首屏跨轮时继续按消息分页。

消息目录以实际独立显示的用户消息为条目，包含提问和中途补充，归入工作过程的回答继续收纳。图片、技能和批注消息使用可读标题。桌面可悬停或点击展开，窄屏使用点击；默认最多 12 条缩略标记，长目录独立滚动，序号和正文各自保持一致的左侧起点。支持搜索、键盘、当前位置高亮和跳转，切换对话清理展开状态、搜索和待处理监听，空对话隐藏入口。新建按钮在侧栏收起和窄屏下可用，沿用当前执行目录及归属，尚无目录时保持首次发送分配流程。 目录和详情卡片各有稳定位置；详情打开后保留各自的操作区域。

思考内容翻译默认关闭，设置开关保存在网页服务。启用后准备本地模型，完整消息的完成事件或已结束历史触发翻译；运行中会话的历史摘要缺少消息状态时，以同轮后续非用户活动确认其已结束，当前流式消息继续等待完成事件，标题优先，正文在折叠期间也可准备。流式阶段及翻译等待期间展示原文，成功后在标题行右侧切换原文与译文，保持展开状态。Markdown 解析只提取普通文字送入引擎，代码、公式与链接目标沿用源码。译文按模型版本和完整原文在同一标签页的内存与会话存储中复用，失败可重试；卸载、关闭翻译或模型切换后忽略迟到结果。模型下载、存储及离线迁移见[部署文档](../deployment.md#思考内容翻译)。

## 工作区、文件与终端

### 详情面板与文件

文件夹选择器默认隐藏名称以 `.` 开头的目录。“显示隐藏文件夹”由选择器持有，切换目录时保留，重新打开选择器时恢复关闭；直接输入绝对路径仍可进入隐藏目录并选择。

聊天区右侧使用统一的对话详情卡片承接文件、变更和终端入口，并在同一卡片中汇总子代理，详情展开与折叠由右侧常驻工具栏统一控制。桌面详情面板占满聊天工作区高度，展开文件、变更或子代理详情时，输入框与错误提示随左侧对话区域收窄，折叠后恢复全宽；窄屏详情覆盖工作区并保留关闭入口。文件下载使用文件名工具栏中的图标，提供可访问名称与悬停提示；卡片支持折叠并回收横向空间；折叠时关闭当前文件、变更或子代理详情并清除选中状态，再次展开回到工作区概览，文件未保存内容继续保留。最右侧始终显示文件、变更、终端和展开/折叠四个按钮的紧凑工具栏，卡片展开及显示详情时继续保留；箭头按实际展开状态切换方向、提示与 `aria-expanded`。文件与变更按钮首次点击打开对应面板，再次点击当前选中按钮折叠详情；点击另一按钮直接切换面板，选中状态随面板同步。终端独立切换并显示状态。对话导航位于小卡片下方并与其中心线对齐，展开与折叠保持导航锚点稳定；桌面与窄屏首次加载均默认折叠，显式展开状态跨布局变化保留，窄屏沿用同一组常驻入口。主消息区的原生纵向滚动条始终贴工作区最右边缘，卡片展开、折叠及详情切换均保持位置，并支持拖动翻阅。对话导航位于滚动条内侧，卡片展开、折叠及文件或子代理详情打开时均保留独立位置和可点击区域。

详情首次加载默认折叠。折叠、新建或切换主对话清除详情选择及待打开文件，重新展开回到概览。

文件面板首次打开后保留挂载，编辑缓冲区按主对话保存。切换目录或文件时按已有未保存确认流程处理；迟到读取和保存只更新原目标。文件面板支持普通源文件、差异片段和带变更装饰的完整文件，切换视图保留编辑内容。

统一差异按区块坐标提供原行号和新行号；删除仅显示原行号，新增仅显示新行号，上下文同时显示两列，元数据省略行号，坐标行隐藏，复制、统计及撤销保留完整差异。完整文件通过逆序还原逐次补丁计算净装饰，删除内容作为只读装饰插回原位置，保存使用实际编辑正文。当前文件与记录冲突时保留差异入口并显示变化状态。 完整文件变更首次打开定位到第一处变更，Markdown 进入源码视图。新增行标绿，删除装饰标红，内容匹配允许无关编辑引起的行号偏移。已删除文件保留差异入口。

本轮文件汇总合并成功完成的修改，默认最多展示五项；按对话、轮次保存实时净差异，历史采用所属轮次记录。按文件撤销由桥接重新读取真实记录，在临时目录校验补丁与源文件后写回；运行、冲突和重复请求分别受控，并广播结果。

文件汇总标题显示文件数量并可收起列表。文件名打开本轮差异片段，行尾箭头打开标记本轮变更的完整文件，源文件按钮打开普通文件。汇总显示各文件增删行数，失败或拒绝的修改不纳入汇总。

Markdown 文件默认使用可编辑的富文本预览，正文、表格和任务列表的修改同步到文件编辑缓冲区，保存按钮和 Ctrl+S 写入当前 Markdown。可切换源码并保留未保存内容，打开及切换视图保留原文件正文，实际编辑后序列化为 Markdown。公式沿用文件中的标准 Markdown 数学语法。代码块提供编辑与预览切换，Mermaid 继续使用公共图表展示。

Markdown 文件使用独立文档排版，宽表格在自身区域内横向滚动；回归检查章节间距及代码工具栏对齐。代码、配置与脚本按文件名高亮，扩展名匹配忽略大小写，未知文本采用纯文本编辑。

文件链接与文件树共用按类型打开的流程，前后端使用同一份格式与 MIME 定义。图片、音视频及 PDF 使用浏览器原生预览，并提供下载和加载失败重试；Office 文档、压缩包及其他已识别二进制文件提供原文件下载。未知类型按 UTF-8 与控制字节检查正文，二进制内容转为下载入口，文本继续编辑；TypeScript 的 `.ts` 扩展名保留代码语义。文件预览及下载通过本站 HTTPS 流式接口读取，支持 GET、HEAD、单段 Range、原始字节及编码后的下载文件名；非预览内容以附件响应。相对链接按所属对话或 Markdown 文件目录解析，本地文件 URI 沿用同一入口。预览跳过文本保存；关闭、切换或重试时停止媒体播放并清理资源，保留未保存正文的确认流程和迟到读取隔离。格式问题按完整打开链路处理，回归使用临时文件及模拟历史，验证各预览类别、下载字节、失败恢复、深浅主题和窄屏。

### 后台任务与交互终端

Codex 后台终端 MCP 默认关闭，通过“其他设置”中的“为Codex开启后台终端功能”启停，按加载对话时的偏好注册。启用后，正常结束轮次时仍在运行的 Codex 原生 `exec_command` 由独立服务保留订阅，原进程继续运行，完成后唤醒原对话。关闭设置后停止接手新命令，已接手的任务继续结算。模型也可直接提交 MCP 后台任务，完成结果共用同一投递机制。结果提交后保持原生订阅，收到所属续跑轮次的终态后释放。完成结果在所属续跑轮次内显示，模型回复接在其后，原生失败或中断有对应标题。网页 `/stop` 同时查询及清理原生终端与当前对话的 MCP 任务，并取消停止任务的续跑。

输入区左侧显示当前对话的后台任务数，点击打开右上角的工作区概览。概览在交互终端入口下方显示任务名、运行时长和单项停止操作。选中任务后在右侧查看终端输出，返回概览继续查看运行列表。运行中尚无终端输出时显示等待状态，并说明重定向的内容保存在目标文件中。向上滚动暂停跟随，回到底部继续跟随，任务结束后保留最终输出。对话切换收起详情并隔离迟到响应。Codex 已投递的完成轮次按原生历史补齐正文及状态，续跑没有可见回复时直接展示任务结果和「查看输出」入口。浏览器只刷新可见的当前对话及已打开的输出详情，终态最后一次读取后停止。

Claude Code 的原生后台任务按所属会话保存任务标识、类型、进度和实际所有者，`/stop` 读取全部后台终端分页并调用原生停止接口。后台任务通知触发的原生自动唤醒按独立轮次保存，轮次绑定真实消息锚点，刷新、编辑回退与分支维持顺序。

交互终端独立于对话任务，按完整启动文件夹隔离。切换到其他文件夹的对话时恢复目标文件夹的列表、选中项和面板开关；没有终端的文件夹默认收起，返回原文件夹恢复原进程和输出。同目录切换对话或模型后端保留终端，shell 内的 cd 保持启动归属，其他文件夹的后台退出不会收起当前面板。面板上边缘支持拖动调高、上下方向键和双击复位，高度比例跨刷新及隐藏保存；缩放和容器高度变化重新限制上限，保留输入框及发送工具栏。列表默认使用紧凑宽度，左边界支持拖动及键盘调节，双击恢复默认；相对宽度跨刷新、隐藏及目录切换保存，窄屏和缩放按实际容器限制宽度。加号创建并选中独立终端，已有终端保留进程与输出，右侧紧凑列表切换活动终端，名称与图标反映实际前台程序（例如 zsh、Python），省去目录及编号；单个终端隐藏列表，终端使用白底，窄屏使用图标列表，名称由可访问标签及悬停提示提供；垃圾桶只结束当前终端，退出后切换到其他运行终端，最后一个退出时收起面板。当前面板依据自身会话集合的运行状态收起，退出事件缺少启动目录时同样生效；Ctrl+D 在 Python 中返回 shell，退出最后一个 shell 才收起面板。隐藏面板保留运行进程，重新打开恢复运行终端。桥接保存运行状态及恢复缓冲区，页面重新连接可恢复显示；关闭终端执行对应清理。重启网页服务会失去进程内终端状态，服务重启流程见[开发者指南](../development.md#从源码运行后台服务)。

## 子代理与共享渲染

设置中的每个后端在同一行提供子代理模型、思考强度和保存操作。模型选项从可用目录取得并以“供应商 / 模型”展示，Codex 候选遵循模型显示偏好。已选模型被隐藏后，以状态占位保留已存配置，候选中省去其名称，恢复显示后恢复选择。强度档位随模型能力提供，选择“原生默认”清除模型覆盖，选择“默认强度”清除强度覆盖。Claude 支持跨已配置供应商选择，原生账户模型使用其解析后的实际 ID。保存直接校验并持久化默认值，保持后端连接、原生主会话和活动任务，完成后广播配置并结束本次请求。后续原生会话配置读取使用最新值，Claude 下一轮通过原生会话级设置更新子代理默认选择，已启动子代理保留原路由及模型。保存失败保留选择并允许重试，清空后恢复原生默认；保存响应直接更新配置，模型目录与账户读取独立于保存操作。Codex 使用原生默认子代理模型，显式任务及自定义代理模型沿用原生优先级；Claude 使用原生强制子代理模型参数，原生 fork 及指定继承模型的技能继续遵循 CLI 的继承语义。模型选择、主供应商及主对话状态保持各自所有权。

Claude 子代理原生历史中，带有 `isSidechain=true` 与 `agentId` 的任务输入以侧链来源建立轮次，即使继承 SDK 入口和父轮次 `promptId`。主对话内部通知继续按其来源字段过滤，子代理任务、工具和回答完整恢复。

子代理按对话 ID 合并 `subAgentActivity` 和 `collabAgentToolCall`，主对话工作过程与详情概览共用入口。只读详情复用完整历史、消息和工作过程，消息路径使用子代理的实际目录。切换代理或关闭详情清理监听并丢弃迟到结果。 工作过程使用中文动作和名称，详情提供返回概览、刷新与失败重试，并保留主对话草稿、附件及未保存文件。

桥接通过父对话协作调用与子代理接收记录核对初始任务和后续消息，按接收者及调用 ID 隔离，保留重复发送并避免原生输入重复。标记为加密的正文在桥接返回前替换为“消息内容已加密”。发送成功而接收记录尚未落盘时，对整条正文符合 Fernet 封包布局的内容立即使用同一状态，检查 Base64URL 编码、版本、固定字段长度及加密块长度；接收后的结构化标记继续覆盖其他密文格式。明文保留原文，包括正文中引用的封包及仅包含相似前缀的文本。失败保留已有内容并可重试。

### Markdown 与媒体

消息、工具结果、子代理及文件预览共用 Markdown 和 HTML 白名单过滤。安全的标题、对齐、图片、`picture` 及折叠内容统一处理，代码保留源码。相对资源以所属对话或文件目录解析；图片失败、主题切换及迟到读取均有隔离处理。

Markdown 中所有文字链接统一使用适配深浅主题的蓝色文字和行内图标，根据目标区分代码、配置、文档、表格、演示文稿、图片、音视频、压缩包、脚本、目录及网页等类型；未识别的本地类型使用通用文件图标。长路径自然换行，保留行号文字、原有文件打开行为和图片链接的预览交互。

对话消息区沿纵向滚动。正文随可用宽度换行，宽公式、代码块和表格各自在可用宽度内横向滚动。

本地图片及历史 `localImage` 附件通过 `fs/readFile` 加载，按对话目录解析相对路径，沿用绝对路径及 `file:`、`sandbox:` 本机引用。大图支持适应窗口及原始尺寸。加载失败可重试，重连后恢复，路径改变关闭旧预览并丢弃原结果。

HTML 图片与 `picture` 候选使用文件或会话目录，保留媒体条件、主题和密度描述。文内链接在所属 Markdown 内定位，覆盖中文、重复标题及折叠内容。安全过滤去除脚本、事件、内联样式和嵌入页面，代码块及行内代码保留源码。

Markdown 正文图片居中展示，等比预览的上限为 640 × 480 像素，窄屏按正文可用宽度缩小，HTML 指定的图片宽度继续生效。消息附件缩略图上限为 320 × 240 像素。点击图片可查看大图，Esc、关闭按钮和空白区域退出后恢复焦点。Mermaid 从本站按需加载，严格模式绘制，默认使用 13px 字号与紧凑节点间距，按可用宽度等比缩小，长图默认在受限高度内滚动，工具栏的四角展开图标可显示完整高度，再次点击四角收起图标恢复紧凑高度，悬停及可访问名称分别为“展开图表”和“收起图表”；消息与文件预览共用展示规则。流程图方向菜单以当前实际布局选中横向或纵向，可选择另一方向进行切换，切换时恢复默认缩放，子图内部的方向声明保持原样。缩放按钮以 25% 为一步，在 50% 至 800% 之间调整，点击百分比复位；图表聚焦后支持 `+`、`-`、`0`，Ctrl+滚轮或触控板捏合缩放。方向、缩放与展开状态归当前图表组件，流式更新与主题重绘保留选择，卸载后恢复默认。查看及复制源码始终使用消息原文。流式未完成或解析失败时保留源码，清理临时节点并隔离旧主题及旧源码结果。

## 账户、登录与外观

### 账户与通知

已有 Codex 对话缺少本地用量快照时，首次读取从原生持久记录补录并保存。分页分支按原生历史引用及截断字节边界恢复对应上下文统计，压缩的 `.jsonl.zst` 记录用解压后的字节位置。后续打开直接读取快照，归档对话跳过补录。

桥接每次启动后，在后端就绪时后台分页核对全部归档和未归档对话。归档对话删除已保存的快照，未归档对话只补录缺少的统计。后台核对只读取原生记录，跳过自动标题生成。核对过程、完成数量和读取错误可通过只读维护状态查询。

创建末尾分支时继承请求发出前的来源用量快照，之后按新对话独立持久化和更新。指定轮次分支仅继承该轮次的已知统计，统计暂缺时等待分支回复上报。原生返回及分支实时上报的用量优先于继承值；Claude 较早轮次分支清除从来源索引复制的最新用量。

对话完成通知默认开启，浏览器已有的手动关闭偏好保持有效。开关表示通知偏好，浏览器尚未授权时提供“允许系统通知”按钮，由用户点击请求权限；已有授权直接生效。正常状态仅展示开关，权限被拒绝、环境不支持及发送失败时显示必要状态。已登录页面观察到活动轮次成功完成后发送一条带对话标题及完成状态的通知；失败、中断、手动整理及历史读取保持各自原有展示。浏览器从桥接活动快照恢复进行中的轮次后可继续接收提醒，刷新和重连恢复已结束历史时保持安静。同源页面通过 IndexedDB 以系统登录用户、对话 ID 与轮次 ID 的唯一主键原子领取提醒，重复事件及多个页面保持一次。发送前重新检查开关、权限和登录用户，关闭提醒立即阻止尚未发送的通知。权限被拒绝、环境不支持及发送失败在设置页明确显示，聊天独立继续。

通知点击优先聚焦原页面并打开所属对话，保留其他对话的草稿与文件缓冲区；原页面已关闭时打开新页面并在登录及初始化就绪后恢复目标。导航事件验证通知所属登录用户，页面监听在登录界面同样有效，卸载时清理监听及待导航目标。提醒开关为浏览器偏好，浏览器权限及系统通知设置共同决定展示；在线页面与服务连接负责接收完成事件。

Claude Code 原生账户额度来自原生 `get_usage` 控制响应，按真实窗口、重置时间和额外用量单位展示；配置外部供应商时显示外部计费状态，余额以该供应商提供的数据为准。上下文用量按原生 token 记录及上下文查询恢复，与账户额度分别管理。

Codex 与 Claude 的所有未归档对话分别在网页配置目录持久保存最近一次收到的完整 token 用量快照，包含累计用量、最近上下文用量及后端实际容量。打开、刷新及桥接重启后通过轻量对话响应读回快照；统计更新优先采用读取期间到达的实时通知。每个对话独立读写，重复值省去写入，并发更新合并为最新快照。归档和删除清除所属统计，归档期间停止采集；恢复归档按普通流程处理，统计暂缺时等待下一次模型回复上报。未归档历史对话首次缺少快照时，按后端原生记录补录。

账户额度按后端实际窗口展示。完整读取替换快照，稀疏通知合并已有元数据；并发读取合并，连接、账户与通知版本共同隔离迟到响应。断线或失败保留上次数据并标记待更新。前台、轮次完成、额度重置及恢复连接触发校准；计时器和页面监听随生命周期清理。

左下角圆环默认折叠，颜色、弧长和数字表示各窗口剩余比例，中心以周或小时缩写区分窗口。详情显示方案、额度及同一行的倒计时和重置时间。点击、键盘、外部点击及 Esc 控制收放，账户切换后折叠，展开保持账户行高度。详情开启时每 30 秒更新本地倒计时，页面可见时每分钟校准额度，收起、断线或卸载分别清理所持计时器。失败时保留旧额度并以灰色圆环及待更新状态提示。

额度详情同时展示所选额度桶的 `credits` 点数余额，通用额度优先使用 `codex` 桶；后端余额四舍五入至最多两位小数并省略末尾的零，`hasCredits: false` 显示零，`unlimited: true` 显示无限额。已有点数信息但余额暂缺时显示余额暂不可用，完整读取未提供点数信息时隐藏该行。仅有点数时仍可通过圆环入口展开详情，断线或读取失败保留余额并标记待更新；通知合并及账户切换沿用账户额度的版本隔离。

### 登录与证书

登录表单保留稳定字段和自动填充语义，从表单真实值取凭据。系统密码验证后通过导航及可用密码管理 API 通知浏览器。双重验证表单显示六位动态码输入和绑定步骤。配置命名验证器后，表单显示名称字段，存在默认验证器时可以留空。服务端只校验所填名称对应的密钥，浏览器不接收绑定清单或密钥。请求失败时在所属表单显示实际错误。局域网会话通过 Cookie 在刷新、浏览器重开及服务重启后恢复。局域网与 P2P 在升级时统一清除缺少当前认证凭据的旧会话。退出或过期返回登录界面，保留草稿和已提交后端任务。局域网密码页与设置页提供按需展开的浏览器证书安装入口，允许未登录下载公开 DER 证书并查看指纹。

密码经标准输入交给 PAM 验证程序，局域网和 P2P 共用登录限流及动态码验证。密码通过后的待验证状态最长保留十分钟，输错五次或服务重启后须重新验证密码。局域网用独立的 Secure、HttpOnly、SameSite=Strict Cookie 恢复待验证页面，P2P 待验证状态归当前 WebRTC 数据通道所有。待验证页面可按所属 Cookie 或数据通道查询当前名称字段的要求，使 CLI 在线添加的绑定可用于已打开的表单。

服务和 CLI 共用私有的 `auth/totp.sqlite`。每个名称对应独立密钥、会话凭据及原子更新的防重放时间步，首次成功验证确认该绑定并签发会话。旧单绑定数据以同一密钥、时间步和会话凭据迁移到 `default`。撤销指定验证器时，两个传输立即拒绝关联会话的新请求，并在会话检查时关闭对应连接及文件流。撤销最后一项后远程登录回到等待绑定。CLI 显式关闭双重验证会清除全部绑定，远程登录在此期间签发的密码会话随重新开启失效。

本机浏览器通过 HTTPS 直接访问时可凭系统密码签发本机会话。签发条件包括同源浏览器请求、连接两端地址相同、请求 Host 与实际服务地址及端口一致，以及请求无代理转发标记。HTTP 和 WSS 使用同样的地址约束校验本机会话。P2P 数据通道使用独立的登录上下文。

服务端会话文件保存会话标识的哈希。局域网使用 Secure、HttpOnly、SameSite=Strict 会话 Cookie，WSS 升级校验来源和会话。P2P 登录表单通过 WebRTC 数据通道发送凭据，公网入口的内容安全策略禁止原生表单提交。浏览器站点存储按授权链接的摘要保存会话令牌与到期时间，重新打开同一条完整链接时通过直连向服务端校验。刷新、网络重连和服务重启也沿用该校验。两种登录会话分别校验，退出或过期撤销关联的业务连接及文件传输。

设置中的「连接与登录」分别展示账号与双重验证、局域网 HTTPS 证书和 P2P 远程访问。账号区域展示退出、双重验证状态及折叠的操作步骤。添加、查看、撤销验证器及关闭双重验证由本机 CLI 管理。通过局域网登录后可启停 P2P，查看入口状态，生成、复制和撤销授权链接。停用后已有授权暂停，重新启用时恢复；撤销指定链接时关闭关联连接并撤销关联登录会话。P2P 工作区显示账号区域和连接方式，退出登录后可在当前链接上重新登录。P2P 授权管理使用局域网登录或本机命令行。

### 视觉与品牌

运行与加载状态使用静态图标，任务进度与耗时按实际数据更新。等待期间省去循环旋转和呼吸动画，使稳定内容仅随进度变化重新绘制；任务完成后清除运行提示并停止对应计时。

侧栏保留品牌图标、Claudex 主名称和独立的 Web 小徽标，其余完整产品名使用 Claudex Web。欢迎区在可用高度减少时独立滚动，输入及工具栏保持可见。

中性灰阶使用统一主题变量，复选框及对勾统一使用 `--check-color`。正文、输入框与提问题干共用字号与行距，本机无衬线字体栈包含中文回退，行高用无单位倍率。字号和界面留白使用字体相对单位，文字条目可随实际内容撑高。

用户消息的复制与编辑按钮紧邻气泡左侧。工作区概览保持紧凑，文件和子代理详情按各自阅读需要配置宽度。聊天正文及输入使用可用全宽，滚动条与正文边距分别计算，右侧导航保持与左侧一致的视觉留白。

项目侧栏的默认宽度、边界与覆盖式布局通过容器和字体相对单位计算。拖动与键盘读取 CSS 实际约束，双击恢复自动宽度。刷新、折叠和窄屏保留比例，并迁移旧像素偏好。布局约束变化或卸载时释放指针捕获。

页面显示功能、结果与必要操作，版本只展示产品版本号；完整构建来源通过构建信息、健康接口及命令行核对。图标统一来自仓库 SVG，兼容浏览器资源由生成脚本维护。

技能入口根据当前目录读取后端已安装技能；Claude Code 使用原生技能目录，选择后将 `/技能名称` 写入下一条消息草稿，保留已有附件；Codex 沿用技能附件流程；插件与连接入口展示后端插件和 MCP 服务状态。这些目录查询由对应弹窗触发，输入提交继续沿用统一消息流程。

## 传输与维护契约

浏览器与桥接共用 `shared/rpc-limits.mjs` 的消息大小限制（64 MiB），桥接发送 JSON 文本时分成至多 1 MiB 的 WebSocket 帧，保持原始图片数据和完整 UTF-8 消息。超限返回可重试错误，隔离当前请求并保留其他页面连接。

P2P 的公网 HTTPS 入口只提供随本机版本发布的静态资源和同源信令。OpenTunnel 在主机终止 TLS，转发到专用回环 HTTP 监听器。Claudex 校验链接后为每次协商创建独立的 WebRTC PeerConnection，使用 STUN 发现地址。链接密钥位于 URL 片段，由当前浏览器标签页保留供刷新和重连使用。直连建立后先在数据通道内检查登录会话或验证系统账户，服务端仅向已认证的连接分派业务请求及通知。协商中和已建立的连接都计入并发上限，每条授权链接最多 8 条，全服务最多 32 条。达到上限时，信令返回 HTTP 429。删除链接或停用功能时关闭所属传输。

WebRTC DataChannel 与局域网 WSS 共用 RPC 分派、订阅及重连恢复。直连帧上限为 16 KiB，队列受限，文件与媒体经浏览器 Service Worker 送入同一连接，以流式分块传输并保留 Range、内容类型及下载头。断线时释放当前请求和流，业务状态由原生后端恢复。隧道失联时，已建直连在原网络路径可用期间继续工作。每次加载页面和重新协商依赖公网 HTTPS 入口。

维护状态使用本机独立凭据与只读 WSS 入口，仅提供就绪、活动轮次和整理占用。空闲重启同时检查轮次与整理；用户终端和后端服务按各自生命周期处理。配置与运行目录来自环境或安装方式，发行包、源码模式和临时测试各用自己的目录。

## 本机 CLI 与网页配置归属

Codex 和 Claude Code 复用本机 CLI 的原有配置、认证、技能、插件和原生历史。网页连接与执行保持相同的原生目录，Claude 原生配置环境沿用既有认证变量，用户明确选择供应商时才应用供应商覆盖。网页自己的配置与持久化状态统一归属 `CLAUDEX_WEB_CONFIG_DIR`，默认 `~/.config/claudex-web`；原生配置目录与网页状态目录独立配置，切换网页目录保持原生目录不变。

Codex 设置中的模型显示偏好由网页后端配置持久保存并广播，模型菜单过滤隐藏项，已有对话保留原模型；设置通过完整原生目录恢复显示。修改显示偏好保持原生执行会话。DeepSeek 默认供应商通过服务端查询官方 `/user/balance`，凭据留在服务器，账户额度快照保存各币种总余额、赠金与充值余额及可用状态。账户行复用额度详情、前台刷新、并发合并、切换隔离和失败保留机制，金额按响应币种展示。

外部供应商账户余额使用响应币种对应的货币符号，金额固定保留两位小数；账户行摘要与展开详情采用相同格式。

Codex 的模型显示设置默认折叠，以轻量文字入口展开紧凑勾选列表，沿用设置页配色与间距，省去列表外框。

Claude Code 网络代理在设置中提供跟随服务环境、关闭和 HTTP，HTTP CONNECT 同时支持 HTTP/HTTPS 网页；旧 HTTPS 选项读取时迁移为 HTTP，显式代理可填写服务器可访问的主机地址及 1～65535 端口。旧配置沿用服务环境。保存前检查所属后端任务占用，忙碌或保存失败时保留旧运行配置及表单输入；成功保存后替换空闲执行服务，后续原生会话使用新配置。关闭代理清除继承的大小写代理变量，本机回环连接始终直接访问。

## 窗口尺寸调节

设置、搜索及其他应用弹窗打开时把焦点移入窗口，背景在打开期间暂停交互。Esc 关闭当前弹窗，焦点回到仍可操作的打开入口。

设置、搜索、重命名、删除确认、目录选择、技能、插件、模型及命令弹窗，以及图片和批注预览的右下角提供尺寸调节手柄。文件预览、文件差异和子代理详情共用的右侧面板通过左边缘调节宽度。支持鼠标及触控拖动、聚焦后的方向键调节、Shift 加速、双击或 Home 恢复默认。窗口手柄支持 Enter 或空格复位。尺寸按用途分别记忆，关闭重开与刷新恢复；尺寸按可用空间比例适应缩放和窄屏，并受当前视口边界约束。详情宽度同步调整聊天与输入区域的避让空间，拖动保留文件编辑和批注内容。项目侧栏、终端高度、终端列表及各类多行表单输入框使用同一套尺寸手柄。默认显示轻量短标记，悬停时增强、拖动时保持高亮，键盘焦点仅围绕局部标记显示。透明操作区与标记分离，方向分别表达调宽、调高或双向调整；失焦、取消或释放捕获结束拖动反馈。输入框保留原有字段、内容与禁用状态，双击或 Home 恢复自动高度。

其他设置的复选框、标签和行尾操作对齐，两种屏宽均按复选框中心距检查等距排列。

## 网页更新与重启

设置中的“更新与重启”显示当前版本、npm 最新稳定版与检查错误。桥接启动时及每小时自动检查，网页发现更新提供设置入口。npm 全局安装可更新并重启，源码部署使用源码更新流程。重启服务在当前版本下同样可用。systemd 用户服务沿用原服务重启，直接启动的进程通过独立维护进程按原 Node.js、参数、目录及环境重新启动。整个网页服务进程重启，网页交互终端随之结束，原生后端继续按各自生命周期执行。独立维护任务持久记录进度，重复操作合并，安装与启动失败提供错误及重试。新包先在隔离目录安装并验证，替换后启动失败恢复原包并核对启动结果。网页重连后保留草稿和文件编辑，用户保存编辑后主动刷新页面加载新资源。

更新及重启请求遇到活动轮次、后台任务、排队输入、待答提问、内部命令、上下文整理或后端 CLI 安装时，结束本次操作并短暂提示用户结束任务后重试。提示五秒后关闭，用户稍后重新发起操作。切换阶段暂停网页提交，避免提交与重启竞争。重启成功后网页显示“服务已重启，请刷新网页”，用户自行刷新。

npm 更新沿用网页服务的 Node.js/npm 路径、npm 配置及网络代理与证书环境，支持 NVM 和自定义用户安装目录。独立维护单元启动失败时立即恢复网页提交，保留失败结果并允许重新执行维护操作。

发现新版时更新按钮可点击，重启按钮在空闲时可点击。部署方式与服务管理条件由服务端在操作请求中校验，失败原因显示在更新卡片内，并允许再次操作。错误、维护进度与完成提示统一放在卡片内的产品信息和操作组下方，长文本按卡片宽度换行。请求及维护任务执行期间暂时禁用按钮；版本检查确认无需更新时保留“无需更新”的禁用状态。

发现新版本后，侧栏底部显示带版本号的更新入口并标记设置按钮；侧栏收起或窄屏时，顶部显示紧凑更新入口。设置页按更新与重启、模型与服务配置、其他设置、连接与登录分组。更新卡片集中显示产品身份和主操作，当前与最新版本在产品名下同行显示，产品图标、版本信息与检查更新、重启服务、更新按钮在卡片中垂直居中并同行排列，空间不足时操作组整体另起一行，可用宽度更窄时组内按完整按钮换行。按钮复用设置页的尺寸和边框，主要更新操作排在最后，有新版时显示“更新至版本号”，无需更新时显示灰色禁用的“无需更新”，按钮数量和顺序保持稳定；检查期间显示进行状态。设置卡片通过间距区分内部内容。其他设置的选项间距保持一致，状态与错误说明紧随所属选项并与选项文字对齐。原生后端的当前版本合并到标题行，正常连接以状态点显示，安装操作失败作为本次设置访问中的短暂提示，重新打开设置跳过历史安装提示，有新版时在按钮直接显示目标版本并允许更新，版本相同或本机更新时保留灰色禁用的“无需更新”按钮；未安装、停用及连接失败保留文字状态。网页主题始终跟随系统。点击更新入口直接打开设置并滚动、聚焦“更新与重启”区域。界面只显示版本、操作与必要状态，检查周期及部署实现保留在部署文档。

维护任务的持久结果用于状态核对，操作提示归属当前设置访问。首次加载、刷新及重新打开设置跳过历史完成和失败提示；当前访问发起的操作按任务开始时间确认结果并只显示一次。关闭设置清除提示并使在途请求的后续反馈失效，后台任务继续按真实状态执行。代理保存反馈五秒后消失，表单错误和实际连接、下载故障按各自当前状态提供处理入口。
