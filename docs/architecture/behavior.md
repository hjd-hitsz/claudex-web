# 产品行为与交互契约规范

本文档定义 Claudex Web 在多端交互、草稿同步、消息渲染与异常恢复中的核心产品行为与交互契约。所有前端交互组件与服务端状态流转必须严格保持以下契约的一致性。

---

## 1. 侧栏导航、会话列表与状态指示

### 1.1 侧栏分区与展示层次

侧栏列表由上至下划分为三个明确的分区：

1. **活动快捷区 (Active Quick Section)**：置顶展示所有当前进行中（包含生成中与后台终端运行中）的会话、带有未读完成提示的会话，以及曾进入快捷区且当前仍处于选中查看状态的会话；
2. **置顶区 (Pinned Section)**：展示用户显式置顶的会话，按当前目录数据顺序展示；
3. **项目组与未分类 (Project Groups & Uncategorized)**：
   - 固定项目置于未固定项目之前，各组内部默认展示最新 5 项，支持“查看更多”展开完整分页；
   - 项目组内自动排除已置顶的会话；
   - “未分类”目录固定排在末尾；支持通过拖拽会话直接调整其所属项目或移入未分类。

### 1.2 会话排序算法 (`thread-order.js`)

侧栏与顶部切换器内会话列表统一执行 `sortThreads` 排序准则：
$$\text{进行中优先} \longrightarrow \text{有效时间倒序} \longrightarrow \text{会话 ID 字典序}$$

- **时间戳选取规则**：
  - 处于活跃生成轮次的会话：取该轮次的开始时间戳 `startedAt`；
  - 处于纯后台任务活动（无生成轮次）的会话：取最近一轮的完成时间戳 `completedAt`；
  - 上述时间缺失时：降级使用会话创建时间 `createdAt`；
  - 归档列表：统一采用归档更新时间 `updatedAt`。

### 1.3 状态指示图标与视觉规范

- **运行中 / 后台终端活跃指示**：
  - 生成中（`running`）与挂载后台活跃任务（`background`）统一在会话行左侧显示灰色主题色的旋转图标（`LoaderCircle`）；
  - 顶部对话切换器通过 `aria-description` 无障碍属性输出「进行中」或「已结束」；
- **未读完成绿点**：
  - 仅当页面处于打开状态且观察到活动轮次在后台成功结束时，在会话左侧标记绿色实心小圆点；
  - 当前会话成功加载历史且视口处于可见阅读状态时，绿点自动清除。

## 2. 草稿生命周期与跨后端共享

### 2.1 正文草稿与多后端同步

- **新建会话草稿**：未提交的新建会话正文统一存储于浏览器 `localStorage["cx-draft-new"]`；用户在 Codex、Claude Code 与 Antigravity 之间切换时，新建正文无缝共享并自动迁移合并；
- **已有会话草稿**：按会话独立保存在 `localStorage["cx-draft-<threadId>"]`，切换或重开会话时完整复原；
- **提交与清理**：每次点击发送或 `Ctrl+Enter` 提交时，前端保存当次提交快照，仅在收到服务端成功确认后清理与快照一致的正文与附件，保留请求等待期间用户新增的编辑内容。

### 2.2 附件与值对象生命周期

- **内存级 Map 持有**：图片、文档附件及代码行引用对象保存在浏览器前端应用实例的内存 `Map` 中，未保存的新会话共用 `null` 键；
- **会话迁移**：当新会话首次发送并由服务端分配实际 `threadId` 后，内存中的附件对象与引用自动无缝迁入新会话键下；
- **数据转换**：图片统一转为 Data URL 随轮次提交；普通文件在发送前异步上传至受限附件目录并生成系统文件引用。

## 3. 代码片段匹配与原位消息编辑

### 3.1 代码粘贴精准匹配 (`codeLine`)

- **内容检索流程**：
  - 用户在输入框粘贴代码片段时，编辑器触发异步调用 `lan/workspace/codeLine`；
  - 宿主服务端在当前工作区利用 `rg --fixed-strings` 执行内容精确查找：单行代码执行全行匹配，多行代码选取特征行初筛文件后再验证连续片段；
  - 片段长度上限为 2,048 字符，允许返回 1 至 3 个匹配文件；
- **标签联动与提交**：
  - 命中唯一匹配时，在输入框上方生成显示文件相对路径与起止行号的引用标签；
  - 提交消息前，编辑器自动等待在途的代码匹配结束，并将确定的绝对路径与行号作为结构化附件注入模型上下文；
  - 用户从正文中删除对应代码片段时，标签自动撤销；
- **职责边界**：`fuzzyFileSearch` 仅用于文件名的模糊补全与检索，与基于文本内容的代码行匹配严格区分。

### 3.2 原位消息编辑与安全回退 (`message-editing.js`)

- **触发准则**：仅允许编辑最近一条用户消息，且该消息必须为所属轮次的首条输入；
- **安全核对与两阶段回退**：
  1. 点击“编辑上一条消息”后，前端重新全量分页拉取服务端历史，核对连接状态并确认当前无进行中的生成轮次；
  2. 服务端优先调用 `thread/revert { beforeTurnId }` 移除原轮次及后续历史；若底层报告不支持该方法，安全回退调用 `thread/rollback { numTurns }`；
  3. 回退成功后前端记录保留的历史轮次 ID 并切换为编辑态；若重新提交失败，再次重试时直接基于已保留的历史发起新轮次，避免重复回滚；
  4. 取消编辑时重新拉取服务端真实历史，恢复界面原状。

## 4. 后台任务概览与交互终端 (PTY)

### 4.1 后台终端与任务面板 (Background Tasks)

- **会话隔离与轮询机制**：
  - 输入框左侧常驻展示当前会话的后台任务计数；
  - 点击展开工作区任务概览，前端以 1.5 秒间隔轮询当前会话的后台任务列表；选中具体任务后以 1 秒间隔轮询最新输出；
  - Codex 从独立后台服务读取输出，Claude Code 从底层 SDK 查询提取输出；任务终态或轮询错误自动停止；
- **停止控制**：支持通过面板单项停止（`thread/backgroundTasks/cancel`）或在输入框执行 `/stop` 一键终止当前会话的全部后台任务。

### 4.2 网页交互终端 (Interactive PTY)

- **宿主进程隔离**：交互终端由服务端宿主 `node-pty` 进程持有，生命周期与会话无关，严格按照启动工作区的绝对目录进行归属与隔离；
- **输出缓冲与状态恢复**：每个终端在服务端环形缓冲保留最近 200,000 个字符；前端通过 `lan/state` 及增量输出事件在刷新或切回目录时完整复原；
- **前端状态记忆**：当前展开的终端面板状态与选中的终端 Tab 按规范化目录存储于 `localStorage`，隐藏面板或切换到其他工作区不影响底层正在运行的 shell 进程。

## 5. 交互提问收纳与划词批注

### 5.1 异步交互提问卡片

- **卡片化呈现**：模型在执行过程中发起的提问请求（`requestUserInput` 或 `agentMessage.questions`），在对应工作过程下方渲染为独立交互卡片；
- **多题翻页与作答**：支持左右翻页作答，每题可独立选择选项、填写自定义正文或点击“拒答此题”；
- **收纳归档**：整批题目全部完成作答或拒答后统一激活提交按钮；提交成功后提问卡片自动折叠收纳进工作过程，历史回溯时支持展开查看作答快照。

### 5.2 划词批注 (Annotations)

- **浮窗与持久化**：在聊天消息中选中文字时浮现批注操作条，编辑内容随当前会话实时持久化；
- **批量合并提交**：用户可对同一轮或多条回复添加多个批注，所有待发批注在主输入框上方集中展示，随下一条用户消息或 `Ctrl+Enter` 一并原子提交。

---

## 6. 系统外观、尺寸调节与异常恢复

### 6.1 弹性尺寸手柄与深浅主题

- **尺寸手柄机制**：项目侧栏、详情面板、交互终端高度及输入框展开窗口均支持拖拽手柄、双击复位与方向键微调，尺寸偏好按视口比例保存并跨刷新恢复；
- **视觉主题一致性**：全站严格适配浅色与深色主题，状态指示灯、图标描边与半透明遮罩遵循统一设计变量。

### 6.2 异常断线与无缝恢复

- **顶部连接栏**：网络断开或底层适配器重连时，顶部轻量显示连接警示条；
- **状态无缝对齐**：连接恢复后，前端优先拉取 `lan/conversations/activity` 快照及会话写入状态，静默对齐离线期间的实时轮次变化，确保用户编辑与阅读不受中断。
