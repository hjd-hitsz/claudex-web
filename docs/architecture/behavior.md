# 功能与状态契约

文件夹选择器默认隐藏名称以 `.` 开头的目录。“显示隐藏文件夹”由选择器持有，切换目录时保留，重新打开选择器时恢复关闭；直接输入绝对路径仍可进入隐藏目录并选择。

供应商模型支持可选显示别名，按供应商及模型 ID 保存到服务端配置。供应商编辑表单默认显示紧凑模型行，点击铅笔展开别名输入，清空使用原名称；供应商保存成功后更新菜单，取消编辑或保存失败时分别放弃或保留表单草稿。模型请求与历史记录继续使用原始模型 ID。

活动轮次的耗时从真实开始时间持续计算，历史读取中的用户及工具消息时间保留为消息事实。轮次成功、失败或中断后使用实际结束时间固定总耗时；刷新、切换和重新展开工作过程继续沿用同一开始时间。

Claude 原生思考按所属 API 消息的内容块顺序保留独立标识，流式、完整消息与历史读取使用相同标识，正文到达时保留已有思考。完整思考以独立标题和可展开正文呈现，单段长文本与多段正文均保留；原生摘要继续按其标题与正文展示。首个思考增量立即归属所属轮次，主对话及子代理采用一致的合并和恢复规则。

本文记录跨模块协作必须保持的产品行为，用于实现评审和回归选择。模块关系见[架构设计](../architecture.md)，测试运行方法见[开发者指南](../development.md)。每项契约同时约束实时通知、历史恢复与页面重新连接；修改行为时同步检查它的所有入口。

## 双后端与供应商

网页安装与启动支持尚未安装任何原生 CLI 的环境，登录后可在设置中安装所需后端。新建 Codex 用户服务通过已有后端启动脚本运行，缺少 CLI 时由 systemd 重试；安装完成后启动原生 app-server，桥接按原连接流程恢复就绪状态。

CLI 一键安装以当前平台原生组件完整下载为前提，完成后安装同一清单版本并校验实际 CLI。下载失败保留已有安装及版本，提供重试。CLI 检测与安装失败在设置中显示简短提示，原始错误保留在默认收起的详情中，展开后限制高度并允许长路径换行。操作成功后清理对应错误和诊断。

自定义供应商在列表的编辑按钮旁提供删除按钮；请求期间禁止重复操作，成功后刷新供应商及模型目录并关闭该供应商的编辑表单，失败保留列表及编辑内容并显示错误。默认供应商通过清空 API Key 停用。

项目模型偏好在所属后端离线时仍可读取和保存；保存成功向所有页面广播所属后端的完整项目偏好，保存失败保留原数据并允许重试。依赖执行状态的目录创建、单文件撤销、整理核对和子代理消息读取在后端就绪后执行。整理占用期间，两端统一暂停开始轮次、补充输入、审查、历史回退和再次整理，历史与项目偏好保持可读。

新对话的项目模型偏好须在当前供应商的模型目录中匹配后恢复；失效偏好依次采用目录内的配置默认模型、原生默认模型及首项，空目录清空模型和思考强度。历史对话保留原模型身份，目录缺失时在模型菜单中显示禁用的不可用状态，用户可主动选择有效模型。

侧栏底部跟随当前对话所属后端，新对话跟随所选模型后端。Codex 显示账户用户名、套餐或 Codex；Claude Code 原生账户显示实际身份及可取得的额度窗口，配置外部供应商时显示供应商名称及外部计费状态。读取失败保留已有数据并提供重试，未取得外部余额时保留实际状态。连接状态同时检查网页连接和所属后端就绪状态。

对话顶部与侧栏各对话仅用图标区分后端，Codex 使用 OpenAI 标识，Claude Code 使用 Claude 官方标识，图标省去名称、悬停提示和附加标签；标识在单后端、断线和刷新后继续显示，依据对话归属确定。页面提供固定的 Codex 和 Claude Code 两个后端，模型菜单以“供应商 · 模型”区分选择。ChatGPT 模型沿用 Codex 原生配置；Claude Code 供应商在设置中配置地址、凭据和模型，多个供应商共用同一个 Claude Code 后端。设置保存和接口校验均约束为两个后端。标题前的复选框即时保存启停；停用后端的对话立即从侧栏移除，正在查看的所属对话回到新对话，重新启用后恢复显示，无需刷新页面。CLI 安装位置及原生目录自动取得。设置自动展示安装状态、当前 CLI 版本与 npm 官方最新版本，未安装提供“一键安装”，已安装提供“一键更新”。服务器持有安装任务，关闭设置或重连后继续展示结果；忙时拒绝更新，失败保留实际错误及重试入口。版本由桥接服务启动时及此后每小时自动检测并广播，网页在各自后端内展示缓存结果，省去手动检测入口和“已是最新”文案。版本查询失败保留已取得的版本并标明查询错误。

新对话选择模型后自动确定后端；已有 Claude 对话空闲时切换供应商和模型，下一轮恢复同一个原生会话。用户消息、助手正文及工具记录沿用原生历史。原生 `origin.kind=task-notification`、`isSynthetic` 及 `isVisibleInTranscriptOnly` 标记的记录保持内部归属；SDK 实时帧按本轮实际提交的输入 UUID 确认用户归属，原生历史中仅继承 `entrypoint=sdk-ts` 与 `promptId`、缺少提交来源与轮次归属的附加记录保持内部归属。工具结果仍更新对应工具；用户主动输入相同文字继续显示。内部记录不创建用户轮次或推进活动时间，已保存的自动唤醒锚点仍用于恢复独立轮次。子代理转发帧在处理主对话生命周期和用量前隔离。运行中的轮次沿用启动配置。同供应商的模型选择仍可为下一轮调整，切换模型保留已有技能与命令目录；跨供应商切换在空闲时进行。新草稿初始化先恢复供应商，再读取其模型、账户及项目偏好。重新打开对话以已保存的供应商与模型恢复，供应商间重复的模型名称按供应商标识区分。已有对话的模型菜单显示所属后端的模型；跨运行时交接按独立需求设计。

## 对话、项目与历史

输入区 `@` 提供文件、目录、技能和同后端其他会话。文件搜索对返回的全部候选按相关性排序后再截取展示数量，名称精确、前缀、连续与紧凑跳字匹配依次优先，仅父目录命中的结果靠后；文件与目录使用相同排序，同分保留原生顺序。空查询与以 `/` 结尾的目录浏览继续按目录优先、名称排序。`@` 查询包含路径分隔符时仅提供文件和目录，分隔符保持路径输入语义；独立的 `/` 查询提供快捷命令和技能。技能候选支持名称、显示名和技能目录的大小写无关模糊匹配，允许按字符顺序输入缩写与跳字；精确、前缀、连续和紧凑跳字匹配依次优先，描述关键词作为低优先级补充。Tab 将当前候选补全为可继续编辑的查询文本并保持建议打开，文件与目录补全完整路径，支持继续输入 `/` 逐级查询；Enter 或点击确认后以独立的行内引用显示，文件按扩展名区分图标，目录、技能与会话使用对应图标；菜单关闭，光标移到引用后的空格。引用节点支持两侧输入、整项删除、撤销、复制粘贴、切换与刷新草稿恢复，发送和消息编辑保持名称与目标。删除引用同时移除该项的提交数据；重复引用保留正文位置，原生元数据按目标去重。Codex 使用原生技能与 thread:// 会话引用，通过同后端只读 read_thread 工具按需读取已保存正文，Claude 技能使用原生命令，会话引用在发送时读取完整分页的用户和助手正文；读取失败保留完整草稿。代码与普通外部链接保留原语义。

侧栏将所有可见的活动轮次对话集中排列在置顶和项目文件夹上方，仅沿用会话行左侧的运行圆圈，省去分区标题和说明。顶部作为快捷入口按最近活动时间排序，同时保留原项目或置顶列表中的会话。成功完成且带未读绿点的会话继续保留顶部快捷入口，当前选中的顶部会话在阅读清除绿点或轮次结束后继续保留，切换会话或新建对话后再移除；其他已结束会话沿用未读状态保留顶部入口。原项目归属、置顶偏好和文件夹收放状态保持不变。活动状态沿用实时轮次事件与重连快照。

对话列表和搜索结果以创建时间、轮次开始时间、有效结束时间中的最大值排序，显示时间沿用相同依据。打开、重命名和切换对话保留活动时间；新轮次开始和结束立即更新顺序。全分页历史补齐时保留已经收到的较新事件。两个后端独立读取，任一后端失败时保留已显示且符合当前归档和搜索范围的记录，其余后端继续更新；侧栏及搜索显示所属后端的实际错误并提供重试。相同查询保留此前已确认的正文匹配记录，修改查询及卸载后忽略旧请求结果。

项目按固定状态分组，固定项目始终位于未固定项目之前，空项目及仅含置顶对话的项目同样遵循此规则，“未分类”始终位于末尾。同类项目的顺序使用页面内快照，归档、恢复和实时活动保留快照；固定与取消固定立即按新状态重新分组，各组内部沿用快照顺序。手动添加或固定的项目跨刷新保存。固定文件夹默认展开，其余默认折叠，每组先显示最新五条；“查看更多”覆盖后端全部分页。“未分类”保留独立归属，新建时按首次发送流程准备工作目录，已有目录可以沿用。

侧栏对话可拖到项目文件夹或“未分类”标题，悬停高亮，保存成功后展开目标并显示对话。移入文件夹为后续轮次选用目标目录，移到未分类保留有效工作目录；运行中的轮次继续完成，后续恢复和新轮次应用迁移结果。归属保存在服务端，刷新、重新连接、归档恢复及其他页面均沿用；保存失败保留原归属、草稿及附件，并提供错误提示。置顶对话移入文件夹后取消置顶。每个网页项目对应一个文件夹，原生历史通过所属后端读取。

主对话与子代理使用 `domain/thread-history.js` 的完整历史读取流程。仅在 `thread/items/list` 明确不受支持时回退到 `thread/turns/list` 的完整消息分页。写入被其他客户端占用时继续提供已保存历史；其他读取错误保留实际错误和重试入口。

分支通过 `thread-catalog.js` 的统一动作创建。读取所有未归档与已归档家族元数据，按真实 `forkedFromId` 关系生成数字后缀，兼容旧网页后缀并保留手动标题。侧栏菜单、回复操作与 `/fork` 共用流程。归档、删除和标题通知同时更新当前对话与列表，旧列表或打开响应保留通知中更新的结果。

Codex 首轮发送后，桥接使用独立连接及临时会话生成简短标题；写入前重新读取目标记录。手动改名、归档、删除及断线取消旧生成任务，生成失败可在后续打开或发送时重试。标题生成的消息和订阅与用户对话隔离。Claude Code 对话沿用其原生标题与网页保存的用户名称。

Claude Code 的模型会话和后台任务由独立执行服务持有。网页关闭、桥接正常重启或异常退出后继续执行，恢复连接时读取同一服务的活动轮次、执行状态及待答提问；同一输入保持一次原生提交。停止或替换执行服务按真实在途请求、活动轮次、整理、队列、提问及后台任务检查占用，忙时保留服务并返回实际状态。代码与运行配置变化在忙时标记待更新，空闲后切换；旧网页桥接重新连接保持较新的执行代际。无活动任务、目标或后台任务的 SDK 会话空闲 5 分钟后释放，再次发送从原生历史恢复。

## 输入、草稿与执行

图片及其他附件随所属对话在当前页面内保留，切换到其他对话再返回时恢复原附件列表；尚未首次发送的新对话同样恢复。移除附件后保持移除，首次发送创建实际对话时迁移附件草稿。一次选择多个文件时，在文件选择框重置前取得全部文件，并将每个文件的读取绑定到原草稿。异步文件读取完成后更新原草稿，发送失败保留附件供重试，发送成功仅清理已提交附件，保留等待期间新增的附件。

正文输入即时更新独立草稿订阅，按对话持久保存。正文编辑区默认容纳两行，随正文、代码及公式的实际高度自动增高，到达可用空间上限后在内部滚动。上边缘公共手柄支持向上拖动增高、方向键调节及双击或 Home 恢复自动高度，手动高度按可用空间比例保存并跨刷新恢复；展开入口打开居中的编辑窗口，复用同一文档实例和撤销栈；底部保留放大前的正文预览、输入框轮廓、工具栏及原有尺寸，页面布局与阅读位置保持连续，背景预览通过隔离节点提供只读展示；通过关闭按钮、Esc 或收起入口返回紧凑输入，保留草稿、选区及原高度选择。编辑窗口复用公共窗口手柄，支持拖动、键盘调节、复位及尺寸偏好恢复。窄屏、缩放及附件变化重新限制高度，发送工具栏保持可见。普通正文和同级列表完整显示，光标与选区由浏览器原生维护；滚动后继续输入时定位到真实编辑位置。加载期间的文本、焦点及完整选区交接给文档编辑器，对话切换后旧实例只清理自己的输入适配。Ctrl+Enter 与发送按钮走同一提交入口，Enter 保留换行；组合输入确认保持正常编辑。输入期间共享状态快照稳定，长历史和文件面板保持渲染隔离。

正文使用 Markdown 富文本编辑，支持 CommonMark、GFM（表格、任务列表、删除线、自动链接及脚注）、数学公式。Mermaid 以普通代码块输入，HTML 保留源码。用户直接编辑排版后的正文及表格单元格，选区格式工具提供常用操作；持久化和发送使用 Markdown。纯文本 Markdown 粘贴直接插入原生文档节点，保留代码语言、公式及表格，选区替换和光标落点遵循粘贴位置；块后保留正文续写位置，一次撤销恢复整次粘贴。富文本副本保留其文档结构，代码内部保留字面内容。编辑器实例及撤销栈归当前对话的输入组件所有，切换对话时销毁；异步初始化及迟到输入回调按挂载生命周期隔离。输入后立即发送读取即时草稿，文件引用和快捷命令继续使用统一入口。编辑器和运行时资源从本站加载，加载期间保留可编辑的 Markdown 文本框。

提交快照包含正文、附件、文件引用和全部批注。失败保留可重试内容，成功只清理与已发送快照一致的草稿；请求等待期间的新输入或批注继续保留。运行中补充使用当前轮次通道，新的轮次带上当前模型、有效思考强度、速度模式和统一执行策略。

新对话的模型和思考强度按项目保存。已有对话打开、刷新及重连时，从后端对话读取与恢复结果取得该对话的模型和思考强度；项目默认选择仅用于新建对话，恢复请求期间的手动调整继续保留。服务端项目设置是跨浏览器恢复来源，本地缓存和待写入选择用于即时交互及失败重试；迁移只补齐服务端缺失值。同项目新建沿用当前有效选择，跨项目恢复目标选择。模型切换保持支持的强度，不支持时由领域规则选择最近的可用档位；迟到恢复保留期间的手动调整。

输入区模型入口按当前选项显示完整的供应商与模型名称，宽度随内容和工具栏可用空间调整，超长名称允许换行。原生下拉选择、键盘操作和禁用状态保持一致，窄屏及页面缩放后发送与停止按钮保持可见。

思考强度通过带离散档位圆点的胶囊滑块调整，标题旁显示当前档位，滑块下方省去重复的档位文字。输入框的紧凑入口展开独立面板，模型弹窗复用同一控件；拖动、点击轨道和方向键使用后端返回的支持档位。模型选择和速度模式分别使用各自入口。

执行策略统一为完全访问。快捷命令注册与参数解析集中在 `features/commands`，菜单、按钮和键盘使用同一入口。`/` 在输入开头、空格及换行后提供命令与技能建议。中途确认网页命令时仅移除当前查询，保留前后正文及附件，执行失败恢复完整草稿；原生命令将已有正文作为参数提交，原生技能将命令放到正文前等待发送。开头命令继续读取后续参数。18 项网页通用命令保留统一用例，Claude Code 当前目录的原生附加命令由实际运行时目录提供。`/init` 保留并打开已有目录指令文件；`/goal` 使用实际目标接口；`/stop` 清理当前对话全部后台终端分页。Claude Code 每次提交按祖先到当前目录读取 AGENTS 项目指令，同目录优先 `AGENTS.override.md`，保留完整原文、路径与作用域；本轮快照替换此前快照，修改和删除在下一轮生效，原生 `CLAUDE.md` 持续适用。完整支持范围见[命令覆盖记录](../cli-command-coverage.md)。

所有公式使用 `$$公式$$`，同一行及换行输入统一生成当前段落内的行内公式，光标停在公式后并可继续正文。单美元符号作为普通文本。闭合前保留可编辑源码，公式可双击或通过键盘重新编辑，修改后以 `$$` 再次闭合。粘贴、草稿恢复和发送沿用同一双美元符号语法；代码块与行内代码保留美元符号源码。

Markdown 输入以逐字键入后自动排版为主要交互，选区格式工具用于补充操作。列表中的行内公式、标题、强调及代码围栏均支持连续输入；代码语言保留在围栏标记中，闭合围栏后回到正文。回归分别覆盖逐字键入、整段插入、粘贴和中文输入法提交，检查可见结果及发送的 Markdown。

链接末尾续写时使用普通正文格式，空格及后续文字保留在链接之外；链接内部继续支持编辑显示文字。粘贴网址、Markdown 链接和草稿恢复遵循同一边界。

最近一轮的初始用户消息提供铅笔形“编辑上一条消息”入口；原消息位置切换为紧凑的 Markdown 编辑框，正文固定两行并通过内部滚动查看长内容；宽度最多为 42rem，窄屏内最多占消息区的 90%。背景、边框、阴影和聚焦边框与底部输入框共用规则，发送使用主操作配色，深色及跟随系统主题同步适配。支持取消、发送、Enter 换行与 Ctrl+Enter 提交。编辑正文、引用附件和批注由消息组件独立持有，底部草稿保持原值。运行中补充消息继续通过运行轮次发送，历史编辑针对完整轮次。

编辑提交先读取完整分页核对最近消息及运行状态，通过 `thread/revert` 回退到原轮次之前；仅在该方法明确不支持时使用 `thread/rollback`。成功回退后清理已移除的历史、时间与差异，再提交新轮次，刷新以实际后端记录恢复。回退失败保留原历史，发送失败保留编辑框及输入，重试核对保留轮次并复用已成功的回退。取消已回退的失败编辑时读取实际历史。连接、写入检查、整理及运行状态限制提交，异步读取和回退响应按对话及打开版本隔离；回退使较早的历史分页请求失效。其他页面收到 `thread/reverted` 时重新恢复所属对话。

Claude Code 编辑及分支通过原生会话分支保存保留前缀，网页逻辑对话与保留轮次标识稳定，原生 UUID 和后台自动唤醒锚点随分支更新。保留的原生别名归属原逻辑对话，列表和删除恢复保持去重；发送失败后重试沿用已成功完成的历史回退。

## 批注、引用与提问

文件引用建议在两个后端保持相同操作：Codex 沿用原生 app-server 查询，Claude Code 通过原生 `file_suggestions` 查询。Claude Code 对话的 `@关键词` 使用 CLI 文件索引和匹配规则，包含文件、目录与中文名称；`@` 及以 `/` 结尾的路径沿用目录浏览。搜索读取失败时显示实际错误，用户可修改关键词重试。

用户消息正文与助手正文共用 Markdown、GFM、公式及安全过滤渲染器，复制和编辑保留 Markdown 源码。引用仅在 Markdown 文本节点中转换，代码、链接和公式保持自身语义。

用户消息统一解析正文、文件引用及回复批注。显示、复制、编辑使用可读内容，提交保留所需引用协议。文件和目录以类型图标及蓝色链接呈现；点击目录定位到文件列表，点击文件在右侧打开。解析失败的普通内容保留原文。

批注解析兼容桌面端的 Markdown 标记和 JSON 格式。选区旁的编辑器只更新草稿；批注按对话保存，可连续添加、重新编辑或移除，再随主输入统一提交。编辑批注时，Enter 与对勾按钮均完成当前批注并将焦点返回主输入框，Shift+Enter 换行，中文输入法选词期间的 Enter 保持输入；Ctrl+Enter 将全部批注、正文和附件统一发送。回复中的编号引用按所属轮次和前置用户消息关联，代码与公式中的标记保留源码。

待答问题按请求 ID 去重，并按对话和轮次展示。提问卡片仅显示标题、题目、选项、回答框和提交按钮；失败时按钮显示“重试”并保留填写内容，具体错误通过按钮提示取得。提问卡片默认使用单行高度的可调节回答框和紧凑间距；Enter 提交整份回答，Shift+Enter 在自由输入中换行，输入法选字期间保留原生键盘行为。提问卡片的选择、私密字段与自由输入独立；异步回答、运行中补充和普通消息分别保持其提交语义。已解决请求跨页面同步，断线恢复采用桥接快照。已回答及已结束的提问收入所属工作过程。

Claude Code 的完整 assistant 消息与流式结束原因分别到达时，按照真实 `message_delta.stop_reason` 确认最终回答或计划，过程文字继续收入工作过程。刷新按相同消息标识恢复已确认的展示类型。供应商 API 错误归入失败轮次和错误提示，公开提示与诊断详情分开，错误正文保持在诊断详情中。

## 整理上下文

整理使用独立的异步任务状态。浏览器在发送前设置占用并保存恢复记录，桥接在提交到轮次结束之间保留订阅。空确认只代表提交成功；实际成功、失败或中断由对应轮次通知或完整历史核对确定。

```mermaid
flowchart LR
  A[提交并持久化恢复线索] --> B[等待开始或结果]
  B --> C[运行中]
  C --> D[完成、失败或中断]
  B --> D
  B --> E[断线后待核对]
  C --> E
  E -->|分页核对实际轮次| C
  E -->|已结束| D
  D --> F[清理恢复记录]
```

整理占用同时约束发送按钮、Ctrl+Enter、运行中补充、重复整理、审查和桥接请求。正文及附件仍可编辑。刷新、重连、回到前台和“检查状态”核对实际记录，旧桥接缺少专用接口时使用已有历史接口。新轮次、无关自动整理及迟到响应按任务标识隔离。

手动整理期间由输入框上方的状态栏统一显示进度、耗时与恢复操作，聊天区隐藏通用工作提示及同一整理轮次的整理活动，保留其他历史和活动。整理结束后，整理记录继续按工作过程规则展示；自动整理沿用原有活动展示。

整理完成提示在关闭、离开该对话或提交有效新消息时收起；空消息保留提示。浏览器重新打开及重连快照只恢复进行中的整理，已结束结果仅更新页面已跟踪的同一任务，已收起提示保持关闭；浏览器离线期间结束的未完成任务仍显示核对后的结果。失败保留待发送内容，其他对话的完成提示保持独立。

## 计划模式

计划模式用于调查需求和制定方案。后端的 `plan` 消息作为独立方案卡片显示部分正文预览，底部渐隐并提供“展开计划”；展开后可从顶部收起，批准与修改按钮保持在预览区外，`item/plan/delta` 追加正文，完成记录替换同一消息；主对话和子代理只读历史采用相同排版。执行工具的 `turn/plan/updated` 步骤列表继续显示为执行进度。

最新方案所属轮次成功结束、且后续尚无用户消息时，提供“批准并执行”和“修改计划”。批准携带完整方案，通过 `turn/start` 显式选择 `default` 模式，确认成功后更新原对话的模式；失败保留原方案及重试入口。修改入口选择计划模式并聚焦原输入框，保留草稿，由用户提交修改意见。批准消息显示为简洁的操作结果，传输与历史保留完整计划。

模式按对话保存在浏览器中，刷新和切换恢复，新建对话使用默认模式。连接、写入检查、整理和消息提交期间统一限制批准，运行期间等待轮次结果。重复点击共用发送占用，提交前重新核对当前对话及方案；发送后的迟到结果按原对话保存模式，底部草稿、附件和其他对话选择继续保留。刷新后从完整历史和轮次状态重新确定批准资格，已有后续用户消息的方案保持为历史展示。

## 消息展示与导航

领域层按轮次组合消息与工作过程，用户提问和中途补充保留独立消息；同轮补充同时按原始消息顺序收入工作过程，摘要行直接显示消息正文，短消息完整可读，长消息省略并可展开正文与附件，实时预览继续显示最新工作活动；工作过程默认折叠，运行时展示最新有效活动，结束后固定耗时。Codex 的 `delivery: async` 中途回复始终收入同轮过程，即使阶段为 `final_answer`；异步投递保留待答提问，回复操作只归属真实最终回答。最终回答的复制及分支按钮位于本轮文件汇总之后，实时生成和历史恢复遵循相同顺序。

全部历史保持连续可滚动。打开对话和回到最新时定位到真实底部，包括消息底部留白；自动跟随期间，输入框恢复、图片、图表及容器变化继续贴底。上翻或目录跳转后保留阅读位置，切换对话清理监听和待处理帧。

主对话打开时，最近一页消息先显示，写入能力检查独立恢复输入，其余历史在后台自动读完并合并；完整轮次时间读取与消息读取并行。补齐较早记录时维持正在阅读的内容位置，实时修改优先于首屏及历史快照。后台分页失败保留已显示记录并提供重试；切换后停止继续分页并丢弃迟到结果。未改变的正文和批注复用 Markdown 解析，普通状态通知和滚动操作保持既有回复渲染结果。

消息目录以实际独立用户消息为条目，支持搜索、键盘、当前位置高亮和跳转；默认缩略标记数量受控。目录和详情卡片各有稳定位置，主消息滚动条贴工作区最右侧。新建按钮在侧栏收起和窄屏下保持可用。

思考内容翻译默认关闭，设置开关保存在网页服务。启用后准备本地模型，完整消息的完成事件或已结束历史触发翻译；运行中会话的历史摘要缺少消息状态时，以同轮后续非用户活动确认其已结束，当前流式消息继续等待完成事件，标题优先，正文在折叠期间也可准备。流式阶段及翻译等待期间展示原文，成功后提供原文与译文切换。Markdown 解析只提取普通文字送入引擎，代码、公式与链接目标沿用源码。译文按模型版本和完整原文在同一标签页的内存与会话存储中复用，失败可重试；卸载、关闭翻译或模型切换后忽略迟到结果。模型下载、存储及离线迁移见[部署文档](../deployment.md#思考内容翻译)。

## 工作区、文件与终端

详情卡片集中提供文件、变更、终端和子代理入口。主对话首次加载默认折叠；显式展开状态跨布局变化保留。折叠、新建或切换主对话清除面板与子代理选择，重新展开回到概览。

桌面详情面板延伸至聊天工作区底部，输入框与错误提示随左侧对话区域收窄；折叠后恢复全宽输入。窄屏详情覆盖聊天工作区并保留关闭入口。文件下载使用文件名工具栏中的图标，提供可访问名称和悬停提示。

文件面板首次打开后保留挂载，编辑缓冲区按主对话保存。切换目录或文件时按已有未保存确认流程处理；迟到读取和保存只更新原目标。文件面板支持普通源文件、差异片段和带变更装饰的完整文件，切换视图保留编辑内容。

统一差异按区块坐标提供原行号和新行号；隐藏坐标元数据，复制、统计及撤销保留完整差异。完整文件通过逆序还原逐次补丁计算净装饰，删除内容作为只读装饰插回原位置，保存使用实际编辑正文。当前文件与记录冲突时保留差异入口并显示变化状态。

本轮文件汇总合并成功完成的修改，默认最多展示五项；按对话、轮次保存实时净差异，历史采用所属轮次记录。按文件撤销由桥接重新读取真实记录，在临时目录校验补丁与源文件后写回；运行、冲突和重复请求分别受控，并广播结果。

Markdown 文件默认预览，可切换源码并保留未保存内容。文本按文件名选择语法；媒体、PDF 和其他二进制由文件类型规则选择预览或下载，支持的流式媒体通过已认证 HTTP 路由读取。目标变化时清理播放器和对象 URL。

Claude Code 的原生后台任务按所属会话保存任务标识、类型、进度和实际所有者，`/stop` 读取全部后台终端分页并调用原生停止接口。后台任务通知触发的原生自动唤醒按独立轮次保存，轮次绑定真实消息锚点，刷新、编辑回退与分支维持顺序。

交互终端独立于对话任务，按完整启动文件夹隔离。切换到其他文件夹的对话时恢复目标文件夹的列表、选中项和面板开关；没有终端的文件夹默认收起，返回原文件夹恢复原进程和输出。同目录切换对话或模型后端保留终端，shell 内的 cd 保持启动归属，其他文件夹的后台退出不会收起当前面板。面板上边缘支持拖动调高、上下方向键和双击复位，高度比例跨刷新及隐藏保存；缩放和容器高度变化重新限制上限，保留输入框及发送工具栏。列表默认使用紧凑宽度，左边界支持拖动及键盘调节，双击恢复默认；相对宽度跨刷新、隐藏及目录切换保存，窄屏和缩放按实际容器限制宽度。加号创建并选中独立终端，已有终端保留进程与输出，右侧紧凑列表切换活动终端，名称与图标反映实际前台程序（例如 zsh、Python），省去目录及编号；单个终端隐藏列表，窄屏使用图标列表，名称由可访问标签及悬停提示提供；垃圾桶只结束当前终端，退出后切换到其他运行终端，最后一个退出时收起面板。当前面板依据自身会话集合的运行状态收起，退出事件缺少启动目录时同样生效；Ctrl+D 在 Python 中返回 shell，退出最后一个 shell 才收起面板。隐藏面板保留运行进程，重新打开恢复运行终端。桥接保存运行状态及恢复缓冲区，页面重新连接可恢复显示；关闭终端执行对应清理。重启网页服务会失去进程内终端状态，服务重启流程见[开发者指南](../development.md#从源码运行后台服务)。

## 子代理与共享渲染

Claude 子代理原生历史中，带有 `isSidechain=true` 与 `agentId` 的任务输入以侧链来源建立轮次，即使继承 SDK 入口和父轮次 `promptId`。主对话内部通知继续按其来源字段过滤，子代理任务、工具和回答完整恢复。

子代理按对话 ID 合并不同协议版本的活动，主对话工作过程与详情概览共用入口。只读详情复用完整历史、消息和工作过程，消息路径使用子代理的实际目录。切换代理或关闭详情清理监听并丢弃迟到结果。

桥接通过父对话协作调用与子代理接收记录核对初始任务和后续消息，按接收者及调用 ID 隔离，保留重复发送并避免原生输入重复。标记为加密的正文在桥接返回前替换为“消息内容已加密”。发送成功而接收记录尚未落盘时，对整条正文符合 Fernet 封包布局的内容立即使用同一状态，检查 Base64URL 编码、版本、固定字段长度及加密块长度；接收后的结构化标记继续覆盖其他密文格式。明文保留原文，包括正文中引用的封包及仅包含相似前缀的文本。失败保留已有内容并可重试。

消息、工具结果、子代理及文件预览共用 Markdown 和 HTML 白名单过滤。安全的标题、对齐、图片、`picture` 及折叠内容统一处理，代码保留源码。相对资源以所属对话或文件目录解析；图片失败、主题切换及迟到读取均有隔离处理。

Markdown 正文图片居中展示，等比预览的上限为 640 × 480 像素，窄屏按正文可用宽度缩小，HTML 指定的图片宽度继续生效。消息附件缩略图上限为 320 × 240 像素。点击图片可查看大图，Esc、关闭按钮和空白区域退出后恢复焦点。Mermaid 从本站按需加载，严格模式绘制，默认使用 13px 字号与紧凑节点间距，按可用宽度等比缩小，长图默认在受限高度内滚动，工具栏的四角展开图标可显示完整高度，再次点击四角收起图标恢复紧凑高度，悬停及可访问名称分别为“展开图表”和“收起图表”；消息与文件预览共用展示规则。流程图方向菜单以当前实际布局选中横向或纵向，可选择另一方向进行切换，切换时恢复默认缩放，子图内部的方向声明保持原样。缩放按钮以 25% 为一步，在 50% 至 800% 之间调整，点击百分比复位；图表聚焦后支持 `+`、`-`、`0`，Ctrl+滚轮或触控板捏合缩放。方向、缩放与展开状态归当前图表组件，流式更新与主题重绘保留选择，卸载后恢复默认。查看及复制源码始终使用消息原文。流式未完成或解析失败时保留源码，清理临时节点并隔离旧主题及旧源码结果。

## 账户、登录与外观

已有 Codex 对话缺少本地用量快照时，首次读取从原生持久记录补录并保存。分页分支按原生历史引用及截断字节边界恢复对应上下文统计，后续打开直接读取快照。归档对话跳过补录。

桥接每次启动后，在后端就绪时后台分页核对全部归档和未归档对话。归档对话删除已保存的快照，未归档对话只补录缺少的统计。核对过程、完成数量和读取错误可通过只读维护状态查询。

创建末尾分支时继承请求发出前的来源用量快照，之后按新对话独立持久化和更新。指定轮次分支仅继承该轮次的已知统计，统计暂缺时等待分支回复上报。原生返回及分支实时上报的用量优先于继承值；Claude 较早轮次分支清除从来源索引复制的最新用量。

对话完成通知默认开启，浏览器已有的手动关闭偏好保持有效。开关表示通知偏好，浏览器尚未授权时提供“允许系统通知”按钮，由用户点击请求权限；已有授权直接生效。正常状态仅展示开关，权限被拒绝、环境不支持及发送失败时显示必要状态。已登录页面观察到活动轮次成功完成后发送一条带对话标题及完成状态的通知；失败、中断、手动整理及历史读取保持各自原有展示。浏览器从桥接活动快照恢复进行中的轮次后可继续接收提醒，刷新和重连恢复已结束历史时保持安静。同源页面通过 IndexedDB 以系统登录用户、对话 ID 与轮次 ID 的唯一主键原子领取提醒，重复事件及多个页面保持一次。发送前重新检查开关、权限和登录用户，关闭提醒立即阻止尚未发送的通知。权限被拒绝、环境不支持及发送失败在设置页明确显示，聊天独立继续。

通知点击优先聚焦原页面并打开所属对话，保留其他对话的草稿与文件缓冲区；原页面已关闭时打开新页面并在登录及初始化就绪后恢复目标。导航事件验证通知所属登录用户，页面监听在登录界面同样有效，卸载时清理监听及待导航目标。提醒开关为浏览器偏好，浏览器权限及系统通知设置共同决定展示；在线页面与服务连接负责接收完成事件。

Claude Code 原生账户额度来自原生 `get_usage` 控制响应，按真实窗口、重置时间和额外用量单位展示；配置外部供应商时显示外部计费状态，余额以该供应商提供的数据为准。上下文用量按原生 token 记录及上下文查询恢复，与账户额度分别管理。

Codex 与 Claude 的所有未归档对话分别在网页配置目录持久保存最近一次收到的完整 token 用量快照，包含累计用量、最近上下文用量及后端实际容量。打开、刷新及桥接重启后通过轻量对话响应读回快照；统计更新优先采用读取期间到达的实时通知。每个对话独立读写，重复值省去写入，并发更新合并为最新快照。归档和删除清除所属统计，归档期间停止采集；恢复归档按普通流程处理，统计暂缺时等待下一次模型回复上报。未归档历史对话首次缺少快照时，按后端原生记录补录。

账户额度按后端实际窗口展示。完整读取替换快照，稀疏通知合并已有元数据；并发读取合并，连接、账户与通知版本共同隔离迟到响应。断线或失败保留上次数据并标记待更新。前台、轮次完成、额度重置及恢复连接触发校准；计时器和页面监听随生命周期清理。

额度详情默认折叠，以圆环显示窗口及剩余比例，展开后显示方案、额度与同一行的倒计时和重置时间。点击外部、Esc 和账户切换收起详情，布局保持账户行高度。

额度详情同时展示所选额度桶的 `credits` 点数余额，通用额度优先使用 `codex` 桶；后端余额四舍五入至最多两位小数并省略末尾的零，`hasCredits: false` 显示零，`unlimited: true` 显示无限额。已有点数信息但余额暂缺时显示余额暂不可用，完整读取未提供点数信息时隐藏该行。仅有点数时仍可通过圆环入口展开详情，断线或读取失败保留余额并标记待更新；通知合并及账户切换沿用账户额度的版本隔离。

登录表单保留稳定字段和自动填充语义，从表单真实值取凭据。成功时通过导航及可用密码管理 API 通知浏览器，失败请求保持表单并显示实际错误。刷新、浏览器重开及服务重启恢复有效会话；退出或过期返回登录界面，保留草稿和已提交后端任务。

主题变量统一维护中性灰阶、蓝色链接和控件状态，显式深色与跟随系统一致。字号和间距采用相对单位，输入框至少容纳两行。侧栏宽度由容器空间、字体和保存的比例共同决定，拖动与键盘读取同一组 CSS 约束。

页面显示功能、结果与必要操作，版本只展示产品版本号；完整构建来源通过构建信息、健康接口及命令行核对。图标统一来自仓库 SVG，兼容浏览器资源由生成脚本维护。

技能入口根据当前目录读取后端已安装技能；Claude Code 使用原生技能目录，选择后将 `/技能名称` 写入下一条消息草稿，保留已有附件；Codex 沿用技能附件流程；插件与连接入口展示后端插件和 MCP 服务状态。这些目录查询由对应弹窗触发，输入提交继续沿用统一消息流程。

## 传输与维护契约

浏览器与桥接共用 `shared/rpc-limits.mjs` 的消息大小限制（64 MiB），桥接发送 JSON 文本时分成至多 1 MiB 的 WebSocket 帧，保持原始图片数据和完整 UTF-8 消息。超限返回可重试错误，隔离当前请求并保留其他页面连接。

维护状态使用本机独立凭据与只读 WSS 入口，仅提供就绪、活动轮次和整理占用。空闲重启同时检查轮次与整理；用户终端和后端服务按各自生命周期处理。配置与运行目录来自环境或安装方式，发行包、源码模式和临时测试各用自己的目录。

测试数据使用模拟后端、临时目录和独立浏览器配置。回归记录应说明目标场景、构建来源和实际结果；环境配置、真实账户和真实对话数据保留在运行环境中。

## 本机 CLI 与网页配置归属

Codex 和 Claude Code 复用本机 CLI 的原有配置、认证、技能、插件和原生历史。网页连接与执行保持相同的原生目录，Claude 原生配置环境沿用既有认证变量，用户明确选择供应商时才应用供应商覆盖。网页自己的配置与持久化状态统一归属 `CLAUDEX_WEB_CONFIG_DIR`，默认 `~/.config/claudex-web`；原生配置目录与网页状态目录独立配置，切换网页目录保持原生目录不变。

Codex 设置中的模型显示偏好由网页后端配置持久保存并广播，模型菜单过滤隐藏项，已有对话保留原模型；设置通过完整原生目录恢复显示。修改显示偏好保持原生执行会话。DeepSeek 默认供应商通过服务端查询官方 `/user/balance`，凭据留在服务器，账户额度快照保存各币种总余额、赠金与充值余额及可用状态。账户行复用额度详情、前台刷新、并发合并、切换隔离和失败保留机制，金额按响应币种展示。

外部供应商账户余额使用响应币种对应的货币符号，金额固定保留两位小数；账户行摘要与展开详情采用相同格式。

Codex 的模型显示设置默认折叠，以轻量文字入口展开紧凑勾选列表，沿用设置页配色与间距，省去列表外框。

Claude Code 网络代理在设置中提供跟随服务环境、关闭和 HTTP，HTTP CONNECT 同时支持 HTTP/HTTPS 网页；旧 HTTPS 选项读取时迁移为 HTTP，显式代理可填写服务器可访问的主机地址及 1～65535 端口。旧配置沿用服务环境。保存前检查所属后端任务占用，忙碌或保存失败时保留旧运行配置及表单输入；成功保存后替换空闲执行服务，后续原生会话使用新配置。关闭代理清除继承的大小写代理变量，本机回环连接始终直接访问。

## 窗口尺寸调节

设置、搜索、重命名、删除确认、目录选择、技能、插件、模型及命令弹窗，以及图片和批注预览的右下角提供尺寸调节手柄。文件预览、文件差异和子代理详情共用的右侧面板通过左边缘调节宽度。支持鼠标及触控拖动、聚焦后的方向键调节、Shift 加速、双击或 Home 恢复默认。窗口手柄支持 Enter 或空格复位。尺寸按用途分别记忆，关闭重开与刷新恢复；尺寸按可用空间比例适应缩放和窄屏，并受当前视口边界约束。详情宽度同步调整聊天与输入区域的避让空间，拖动保留文件编辑和批注内容。项目侧栏、终端高度、终端列表及各类多行表单输入框使用同一套尺寸手柄。默认显示轻量短标记，悬停时增强、拖动时保持高亮，键盘焦点仅围绕局部标记显示。透明操作区与标记分离，方向分别表达调宽、调高或双向调整；失焦、取消或释放捕获结束拖动反馈。输入框保留原有字段、内容与禁用状态，双击或 Home 恢复自动高度。

上传附件保留原始字节与文件元数据，草稿仍归所属对话。图片使用大图预览，UTF-8 文本、音视频和 PDF 按格式展示；压缩包、Office 及其他二进制文件提供信息与原文件下载。非图片附件发送前由公共工作区服务写入网页配置目录下的受限附件目录，再以本机文件引用提交给所属后端；上传失败保留草稿，重试复用已上传路径。预览对象 URL 由窗口持有并在关闭时释放。

## 网页更新与重启

设置中的“更新与重启”显示当前版本、npm 最新稳定版与检查错误。桥接启动时及每小时自动检查，网页发现更新提供设置入口。npm 全局安装可更新并重启，源码部署使用源码更新流程。重启服务在当前版本下同样可用，操作要求当前进程属于安装的 systemd 用户服务。整个网页服务进程重启，网页交互终端随之结束，原生后端继续按各自生命周期执行。独立维护任务持久记录进度，重复操作合并，安装与启动失败提供错误及重试。新包先在隔离目录安装并验证，替换后启动失败恢复原包。网页重连后保留草稿和文件编辑，用户保存编辑后主动刷新页面加载新资源。

更新及重启请求遇到活动轮次、后台任务、排队输入、待答提问、内部命令或上下文整理时，结束本次操作并短暂提示用户结束任务后重试。提示五秒后关闭，用户稍后重新发起操作。切换阶段暂停网页提交，避免提交与重启竞争。重启成功后网页显示“服务已重启，请刷新网页”，用户自行刷新。

npm 更新沿用网页服务的 Node.js/npm 路径、npm 配置及网络代理与证书环境，支持 NVM 和自定义用户安装目录。独立维护单元启动失败时立即恢复网页提交，保留失败结果并允许重新执行维护操作。

发现新版本后，侧栏底部显示带版本号的更新入口并标记设置按钮；侧栏收起或窄屏时，顶部显示紧凑更新入口。设置页按更新与重启、模型与服务配置、其他设置、网页登录分组。更新卡片集中显示产品身份和主操作，当前与最新版本在产品名下同行显示，产品图标、版本信息与检查更新、重启服务、更新按钮在卡片中垂直居中并同行排列，空间不足时操作组整体换行，三个按钮保持同行，复用设置页按钮的尺寸和边框，主要更新操作位于右侧，有新版时显示“更新至版本号”，无需更新时显示灰色禁用的“无需更新”，按钮数量与位置保持稳定；检查期间显示进行状态。设置卡片通过间距区分内部内容。其他设置的选项间距保持一致，状态与错误说明紧随所属选项并与选项文字对齐。原生后端的当前版本合并到标题行，正常连接以状态点显示，安装操作失败作为本次设置访问中的短暂提示，重新打开设置跳过历史安装提示，有新版时在按钮直接显示目标版本并允许更新，版本相同或本机更新时保留灰色禁用的“无需更新”按钮；未安装、停用及连接失败保留文字状态。网页主题始终跟随系统。点击更新入口直接打开设置并滚动、聚焦“更新与重启”区域。界面只显示版本、操作与必要状态，检查周期及部署实现保留在部署文档。

维护任务的持久结果用于状态核对，操作提示归属当前设置访问。首次加载、刷新及重新打开设置跳过历史完成和失败提示；当前访问发起的操作按任务开始时间确认结果并只显示一次。关闭设置清除提示并使在途请求的后续反馈失效，后台任务继续按真实状态执行。代理保存反馈五秒后消失，表单错误和实际连接、下载故障按各自当前状态提供处理入口。

运行与加载状态使用静态图标，任务进度与耗时按实际数据更新。等待期间省去循环旋转和呼吸动画，使稳定内容仅随进度变化重新绘制；任务完成后清除运行提示并停止对应计时。

创建对话分支时显式传递来源对话的模型和思考强度。当前对话采用创建动作开始时的输入区选择，侧栏其他对话通过原生读取结果取得配置；分支恢复继续采用后端保存结果。回归覆盖全局默认模型与来源不同及非当前对话分支。

### 目标交互

`/goal` 进入主输入框的目标输入状态，并切换为执行模式；退出目标输入保留正文和附件。提交目标使用 `thread/goal/set`，已有目标先显示替换确认。附件先写入受限附件目录，再将本机文件引用纳入目标。目标摘要常驻输入区上方，按原生状态展示追踪、暂停、阻塞、用量限制、预算限制及完成，提供暂停、恢复、编辑与清除操作。刷新、重连与切换对话重新读取所属目标，实时通知优先于迟到响应。

编辑在右侧详情完成，标题与关闭入口同行，紧凑工具栏集中展示更新时间、还原图标和保存按钮，正文占满中间可用区域。Token 预算默认收起于底部辅助区域，展开后编辑。支持 Markdown、还原与 Ctrl+Enter 保存；编辑草稿按对话保存，保存失败保留内容。保存正文沿用客户端激活目标的语义。目标操作按对话串行，断线、整理及提交期间暂停写入；预算及完成判断由所属原生后端维护。
