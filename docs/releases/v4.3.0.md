# Claudex Web v4.3.0

## 新增重要功能

- **Antigravity 秘书**。在服务电脑安装并登录 Antigravity CLI，再到「设置 → 后端 → Antigravity」启用。点击顶部文件夹左侧的后端图标切到 Antigravity，再在输入区选择已开启接收委派的 Codex 或 Claude Code。秘书可直接答复，也可将任务交给所选执行端在后台处理。执行端提出的问题、权限审批和任务结果会回到原对话，侧栏可查看 Antigravity 账户额度。（[a4f1712](https://github.com/hjd-hitsz/claudex-web/commit/a4f171239bfa378b714827020cfc81dec9bc7f1d)）
- **Codex 与 Claude Code 双向委派**。在「设置 → 委派」为接收方选择模型和思考强度，并为发起方选择或编辑秘书提示词。Codex 和 Claude Code 初次使用时默认由原生助手答复。在输入区开启「委派模式」后，秘书从首轮起就能直接答复、写作或向另一端派单，重开对话会恢复原来的模式。Claude Code 继续使用原有工具、权限和已配置的模型供应商，秘书和执行端按当前项目规则各自分工。重复提交同一委派时会复用已有任务回执。（[eacbd7c](https://github.com/hjd-hitsz/claudex-web/commit/eacbd7c5b22f0696b29c67dd4a90615c23d4c28c)、[2d38fe9](https://github.com/hjd-hitsz/claudex-web/commit/2d38fe920e2eba5f5a92064bd9feabfeb4d13a45)）
- **MCP 信息请求**。Codex 的 MCP 工具需要补充资料时，可直接在对话中填写、提交或取消表单。工具需要外部授权时，卡片会显示目标网站，点击链接在新标签页完成授权，再回到对话确认或取消。（[c6107d2](https://github.com/hjd-hitsz/claudex-web/commit/c6107d2861e2295593295c184087b91639f332be)）
- **Antigravity 技能、命令与附件**。从输入区的「技能」或 `/skills` 搜索并选用当前项目的技能，也可输入 `/` 查看并执行当前秘书提供的斜杠命令。重启后重开对话，仍可继续使用这些命令。文件附件随消息一同发送，可以从历史消息中打开。（[1a09586](https://github.com/hjd-hitsz/claudex-web/commit/1a095865f2a08e8e7635afe1c70b2120a6244daf)）
- **Antigravity 上下文用量**。在输入区的上下文指示中查看当前占用和模型窗口上限，展开可看各轮的输入、缓存输入、输出、推理输出和 Token 总量。手动整理会在同一网页对话中从摘要继续，正在委派时可等执行结果返回后再整理。自动整理完成也会留下记录。（[1a09586](https://github.com/hjd-hitsz/claudex-web/commit/1a095865f2a08e8e7635afe1c70b2120a6244daf)）

## 其他改进与修复

- 主对话右侧的摘要卡片可以打开委派结果或后台终端输出，左侧可展开工作过程，秘书的答复单独显示。委派结果保留执行端最后一轮的最终答复原文。秘书可按命令、参数或文件名查找工具调用，再按调用 ID 查阅原始输入和输出。网页仍可查看完整执行过程。补问启动的后台任务随该次补问结算，Codex 任务带有文件补丁时也能结束并显示结果。（[24b865f](https://github.com/hjd-hitsz/claudex-web/commit/24b865f1aa081b3da6b4893e06215f53b1c5b641)、[2bce533](https://github.com/hjd-hitsz/claudex-web/commit/2bce533bec417242e9dd9ea84a382412af680cfa)）
- 打开委派或子代理详情，可查看执行端的上下文占用、窗口上限和累计整理次数。子代理详情中的执行信息同排显示，用量随执行更新。列表显示委派任务名称、执行端和状态，同名任务以短 ID 区分。主动停止的任务显示「已停止」。（[24b865f](https://github.com/hjd-hitsz/claudex-web/commit/24b865f1aa081b3da6b4893e06215f53b1c5b641)、[2bce533](https://github.com/hjd-hitsz/claudex-web/commit/2bce533bec417242e9dd9ea84a382412af680cfa)、[380e26f](https://github.com/hjd-hitsz/claudex-web/commit/380e26f8380e2932d7413584a13efd1ca4736c0d)）
- 侧栏、顶部对话切换器和助手的活跃对话查询会一致显示仍有工作的会话。后台终端、目标、子代理、委派、跨会话投递、上下文整理和文件撤销期间都会保留活动状态。跨会话消息可登记等待回复，收到关联回复或发起方结束等待后会更新状态。委派中的模型提问显示「等待用户输入」，权限请求显示「等待审批」。（[b1ca566](https://github.com/hjd-hitsz/claudex-web/commit/b1ca5660d28a411081f81442d916dfe4520465a9)、[c6107d2](https://github.com/hjd-hitsz/claudex-web/commit/c6107d2861e2295593295c184087b91639f332be)）
- 点击顶部文件夹左侧的图标即可切换后端，模型菜单只显示所选后端的模型。「设置 → 后端」逐个列出后端，并可勾选 Antigravity 中要显示的模型。切换后端或刷新草稿时会恢复该项目上次选用的模型和思考强度，Antigravity 的模型列表会自动刷新，切回时可直接使用已载入的列表。重开 Antigravity 历史对话或收到委派结果时沿用该对话的模型和思考强度，模型被隐藏或暂时不可用时，输入区会显示原模型名称及状态。（[a4f1712](https://github.com/hjd-hitsz/claudex-web/commit/a4f171239bfa378b714827020cfc81dec9bc7f1d)）
- 新对话的正文、图片、文件附件和代码行引用可在切换后端后继续使用，升级时会自动合并旧版分后端保存的新对话草稿。新建时沿用当前的委派开关，在 Antigravity 中新建也会保留当前选择的执行端。已有对话按各自保存的选择打开。（[cb1f2f8](https://github.com/hjd-hitsz/claudex-web/commit/cb1f2f85e45f1c20b86496a8606558bc18cdac39)）
- Antigravity 生成中可补充说明，已经显示的文字和工具结果会保留，新说明从下一次模型请求起生效。工作过程按工具调用和文件变更分隔思考摘要，长摘要可以展开。Antigravity 从首轮就可按秘书角色派单。它自己的工具请求会自动同意，命令失败时会显示实际输出，模型设置通知会从聊天正文和历史中隐藏。（[d6430fb](https://github.com/hjd-hitsz/claudex-web/commit/d6430fbe613000412a9111219efd1f1f8131c679)、[1a09586](https://github.com/hjd-hitsz/claudex-web/commit/1a095865f2a08e8e7635afe1c70b2120a6244daf)）
- Antigravity 可从指定轮次继续为新对话，也可编辑任一历史轮次的首条消息，在原网页对话中重发。继续时会带上保留的消息和工具结果摘要。网页改名同步到 Antigravity 历史，归档和恢复会在该历史中隐藏或重新列出会话，确认删除会一并移除对应的 Antigravity 会话记录。（[1a09586](https://github.com/hjd-hitsz/claudex-web/commit/1a095865f2a08e8e7635afe1c70b2120a6244daf)）
- 在 Antigravity 的工作区可查看当前对话委派的后台终端及其输出，单独停止任务或用 `/stop` 清理。没有运行任务时，计数和列表会隐藏。「插件与连接」显示已安装的插件、MCP 配置和当前秘书对话已加载的委派工具。（[1a09586](https://github.com/hjd-hitsz/claudex-web/commit/1a095865f2a08e8e7635afe1c70b2120a6244daf)）
- 已结束的 Antigravity 委派可从原对话重开，网页或任务服务重启后仍可查看执行记录。大量输出时的任务状态读取更稳定，Antigravity 恢复连接后，侧栏会自动刷新对话列表。（[a4f1712](https://github.com/hjd-hitsz/claudex-web/commit/a4f171239bfa378b714827020cfc81dec9bc7f1d)、[eacbd7c](https://github.com/hjd-hitsz/claudex-web/commit/eacbd7c5b22f0696b29c67dd4a90615c23d4c28c)）
- Claude Code 整理上下文后，重开对话仍按时间顺序显示历史、工具结果和后续答复，工作过程中的子代理卡片对应实际启动的子代理。会话也取消了内置的提交与拉取请求流程指引，以及自动添加的提交、拉取请求和会话链接署名。（[08e962f](https://github.com/hjd-hitsz/claudex-web/commit/08e962f451f34f09c72173bb56122dc32420e5a5)、[cb1f2f8](https://github.com/hjd-hitsz/claudex-web/commit/cb1f2f85e45f1c20b86496a8606558bc18cdac39)）
- 使用 systemd 托管时，提交空闲重启后命令即可返回。网页服务会在当前任务和上下文整理结束后重启，等待进度和重启结果可在用户服务日志中查看。（[24b865f](https://github.com/hjd-hitsz/claudex-web/commit/24b865f1aa081b3da6b4893e06215f53b1c5b641)）
