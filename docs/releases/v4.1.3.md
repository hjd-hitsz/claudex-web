# Claudex Web v4.1.3

- 设置中可为 Codex 与 Claude Code 分别选择子代理模型和思考强度，并在同一行保存。Codex 候选遵循“显示的模型”偏好，Claude Code 支持为子代理选择其他供应商的模型。（[3b71464](https://github.com/hjd-hitsz/claudex-web/commit/3b71464bdec72fa8449057d47810a69fd92e88db)）
- `/goal` 支持直接在输入框描述目标，持续查看状态并暂停、恢复或清除。侧边编辑支持 Markdown、预算和草稿恢复，替换目标前可确认。（[7490ea9](https://github.com/hjd-hitsz/claudex-web/commit/7490ea92bc076ffbcb6307a168025d73141d8ad6)）
- 正文图片居中显示，并增大预览尺寸，便于阅读图表细节，窄屏按可用宽度等比缩小。（[573c07b](https://github.com/hjd-hitsz/claudex-web/commit/573c07b725dd648075f9646bcc23d2d4456f1a88)）
- Markdown 文件预览支持直接编辑正文、表格及任务列表，并可保存或切换源码继续编辑。（[123b6db](https://github.com/hjd-hitsz/claudex-web/commit/123b6db764fd974c6cd045a6481c8cbea37afa3d)）
- 创建对话分支时继承来源对话的模型和思考强度。（[1f698b6](https://github.com/hjd-hitsz/claudex-web/commit/1f698b61b956b99ec6da0f609e266a95804c8065)）
- 修复首次打开 Codex 对话时出现连接错误、需要手动重试的问题，恢复期间保留历史、输入草稿及附件。（[a62f4a6](https://github.com/hjd-hitsz/claudex-web/commit/a62f4a68afbab9c5d3ee294288ddb4bb2a4da7ab)）
