# Claudex Web v4.1.1

- 消息输入区随正文、代码和公式自动增高，支持拖动调高及独立窗口编辑长内容，放大时保留底部预览和页面位置。正文中间粘贴保留代码格式、前后文字及整次撤销。（[d57d1be](https://github.com/hjd-hitsz/claudex-web/commit/d57d1be)）

- Mermaid 图表支持横向与纵向切换、完整高度展开与收起，以及按钮、键盘和 Ctrl+滚轮缩放与复位。默认字号和节点间距更紧凑，长图高度与正文比例更协调。（[d342926](https://github.com/hjd-hitsz/claudex-web/commit/d342926)）

- 输入正文中途在空格或换行后使用 `/` 可查看命令与技能建议，选择命令时保留前后正文和附件，执行失败后恢复草稿。（[dbc8074](https://github.com/hjd-hitsz/claudex-web/commit/dbc8074)）

- 输入区模型名称随当前选项自适应宽度，竖屏保留完整名称，超长名称在窄屏内换行。（[dd20ea9](https://github.com/hjd-hitsz/claudex-web/commit/dd20ea9)）

- 设置中的版本信息与操作按钮同行排列，减少纵向留白。“通知与翻译”更名为“其他设置”，选项间距统一，状态说明贴近对应选项。（[5acc2ff](https://github.com/hjd-hitsz/claudex-web/commit/5acc2ff)）

- CLI 一键安装先下载校验当前平台组件，再安装并核对版本。下载失败保留已有 CLI，错误详情可展开查看，窄屏长路径完整换行。修复新建 Codex 后端服务时因监听地址末尾斜杠导致启动失败的问题。（[bef8fb8](https://github.com/hjd-hitsz/claudex-web/commit/bef8fb8)）

- 执行过程中的异步中途回复与同轮补充统一收纳到工作过程中，保持聊天区最终回答的展示顺序。（[f7cd966](https://github.com/hjd-hitsz/claudex-web/commit/f7cd966)）

- 运行与加载提示采用静态状态图标，减少持续等待时的绘制开销，同时保留进度、计时和完成反馈。（[9150d3c](https://github.com/hjd-hitsz/claudex-web/commit/9150d3c)）

- 收起侧栏后，键盘焦点返回页头展开按钮，方便继续操作。（[de71ba2](https://github.com/hjd-hitsz/claudex-web/commit/de71ba2)）
