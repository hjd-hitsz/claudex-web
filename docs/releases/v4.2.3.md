# Claudex Web v4.2.3

- 输入框工具栏显示当前对话的活跃子代理数量，点击可打开工作区概览查看各子代理的状态和对话。（[748f50f](https://github.com/hjd-hitsz/claudex-web/commit/748f50f37be813edf4b1d5e1fa30e7d444f32d22)）
- Codex 启动后台终端时必须估算检查时间。依赖其他会话时，模型会直接询问对方的状态和预计就绪时间，再据此安排或调整检查。到时仍在运行会唤醒原对话，任务面板会显示检查安排。（[dd971e1](https://github.com/hjd-hitsz/claudex-web/commit/dd971e16d4288e64a413703bc8b8281c76020a64)）
- Codex 和 Claude Code 会话可主动查找同后端实例的活跃会话，协调重叠工作、共享资源和交接。收到会话问题会在掌握事实后主动回复。回复自动送回原提问会话，上一轮结束时会开启新一轮。服务重启后也能按消息 ID 找回回执和回复。（[dd971e1](https://github.com/hjd-hitsz/claudex-web/commit/dd971e16d4288e64a413703bc8b8281c76020a64)）
- 使用 DeepSeek 时，侧栏账户显示官方标识，余额圆环中显示钱包图标。（[70bcb0d](https://github.com/hjd-hitsz/claudex-web/commit/70bcb0ddbbb2a4e3914ff3dc3292ff2dd6a1ddab)）
- 提问一次只显示一题，可用左右按钮自由切换、单独拒答或恢复作答。整批共用一个提交按钮，全部拒答时立即结束提问。（[a04324d](https://github.com/hjd-hitsz/claudex-web/commit/a04324d3f0f40132a3bcc8b505108d9c48990018)）
- 粘贴代码后发送会先等文件匹配完成，再一并提交正文、绝对路径和行号。发送成功后清理已提交的草稿和文件标签。（[d5c6e51](https://github.com/hjd-hitsz/claudex-web/commit/d5c6e511ee3fba8a7cbc61e28554e5b8f327d1b1)）
- 中文组合输入时根据原选区恢复偏离的光标，并在确认文字误写到相邻段落时还原原文。临时文本框完成选词后再切换到富文本，草稿只保存确认后的内容。（[c1f376c](https://github.com/hjd-hitsz/claudex-web/commit/c1f376cb37136df873fd52a5bd6ac8233d07256f)）
