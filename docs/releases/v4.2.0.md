# Claudex Web v4.2.0

## 新增重要功能

- **Codex 后台终端**。在「设置 → 其他设置」开启扩展后，耗时命令可以在当前轮次结束后继续运行，任务完成时自动唤醒原对话。输入框旁的任务计数可打开任务列表，查看实时输出或单独停止任务。Codex 任务支持下载完整日志，`/stop` 可管理当前对话的原生终端和扩展任务。自动续跑失败或没有返回正文时，原对话仍会显示任务结果和日志入口。（[f71d8f3](https://github.com/hjd-hitsz/claudex-web/commit/f71d8f39181025bda95f134bb2b25aea6df8de94)）
- **P2P 远程直连**。在「设置 → 连接与登录」开启 P2P 后，可生成长期授权链接，从局域网外用浏览器通过加密的 WebRTC 直连访问聊天、文件和终端。刷新、重连或在同一浏览器重新打开链接时可恢复有效登录。撤销链接会断开相关连接并使对应的登录会话失效。（[b40f98a](https://github.com/hjd-hitsz/claudex-web/commit/b40f98a267f090fe7bfdda750e5b30f632b15cb1)）
- **双重验证登录（2FA）**。从其他设备、代理入口或 P2P 登录时，默认在系统密码后验证六位动态码。同一实例的多位使用者可以分别绑定具名验证器，撤销某个验证器时会同时撤销通过它登录的会话。服务电脑上的浏览器直接访问本机 HTTPS 端口时可凭系统密码登录。缺少新版认证凭据的旧网页会话需要重新登录。（[08cdb45](https://github.com/hjd-hitsz/claudex-web/commit/08cdb4576e335147546c6eb100180eebf7bfe5cf)、[a46e5e5](https://github.com/hjd-hitsz/claudex-web/commit/a46e5e5eb119422aace5b6a0488444382b80d5ca)）

## 其他改进与修复

- Codex 目标可以跨轮次持续运行，自动续跑会处理已发送的中途消息。Claude Code 执行服务等待空闲更新时，设置页继续显示实际连接状态，现有对话可以继续使用。（[d3a53ec](https://github.com/hjd-hitsz/claudex-web/commit/d3a53ecba1559ec3b6b0001ceb00a60702b680fb)、[d0e89fe](https://github.com/hjd-hitsz/claudex-web/commit/d0e89fed3f8dced94773562c6906f6b5d8d3d85c)）
- 文件面板的 Markdown 预览恢复标题层级和段落间距，代码块的编辑与复制按钮并排显示，宽表格可在预览内横向滚动。不同对话打开同一路径时，各自保留未保存的编辑。（[e45f912](https://github.com/hjd-hitsz/claudex-web/commit/e45f912d833e55e2394b6aa2d8fc592c55fcf4d3)、[2590ef4](https://github.com/hjd-hitsz/claudex-web/commit/2590ef4e2ab164ab3ce76f3df9d86e2148d1132e)）
- 流式回复期间，已显示的 Markdown 链接、图片、图表和模型控件按需更新。模型选择器、`/model` 和子代理设置统一隐藏已设为不可见的模型。（[2590ef4](https://github.com/hjd-hitsz/claudex-web/commit/2590ef4e2ab164ab3ce76f3df9d86e2148d1132e)）
- 弹窗关闭后焦点回到触发入口，对话菜单支持按 Esc 关闭，桌面侧栏和移动端抽屉分别记住开合状态。窄屏放大时，更新与重启按钮保留完整文字，长模型名也能给消息输入留出两行空间。手机上的宽公式、代码块和表格在各自区域内横向滚动。（[2590ef4](https://github.com/hjd-hitsz/claudex-web/commit/2590ef4e2ab164ab3ce76f3df9d86e2148d1132e)、[75cc522](https://github.com/hjd-hitsz/claudex-web/commit/75cc522b5d553193a5f327a135948df4f908e142)）
- 「连接与登录」按账号与双重验证、局域网 HTTPS 证书、P2P 远程访问分区显示。「其他设置」的复选项采用一致的行距。（[b40f98a](https://github.com/hjd-hitsz/claudex-web/commit/b40f98a267f090fe7bfdda750e5b30f632b15cb1)、[d9f93cc](https://github.com/hjd-hitsz/claudex-web/commit/d9f93cc18e8afeef25776c94e3cdae126a10178a)）
