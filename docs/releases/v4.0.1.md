# Claudex Web v4.0.1

- 侧栏支持将 Codex 与 Claude Code 对话拖到其他项目文件夹或“未分类”，刷新后保留归属，移入项目后继续在目标目录工作。（[78832f3](https://github.com/hjd-hitsz/claudex-web/commit/78832f3)）
- 正在运行和完成未读的会话集中显示在侧栏项目列表上方，原文件夹和置顶入口继续保留，当前查看的顶部会话在阅读后保留，离开时自动收起。（[68a904c](https://github.com/hjd-hitsz/claudex-web/commit/68a904c)）
- 工作过程按插入位置预览运行中补充的消息正文，长消息可展开查看全文和附件。（[9eb099d](https://github.com/hjd-hitsz/claudex-web/commit/9eb099d)）
- 文件引用支持 Tab 逐级补全路径、Enter 确认为引用，直接匹配的文件和目录优先展示，路径输入保持目录分隔符的正常行为。（[b64d44d](https://github.com/hjd-hitsz/claudex-web/commit/b64d44d)）
- 缩短工具记录密集的长对话完整加载等待，并修复其他客户端同时打开会话时，网页重新进入、读取历史和恢复发送可能等待两分钟的问题。（[5a5a0f6](https://github.com/hjd-hitsz/claudex-web/commit/5a5a0f6)）
- Claude Code 自定义供应商提供删除按钮，删除后同步更新供应商和模型列表。（[d9925d0](https://github.com/hjd-hitsz/claudex-web/commit/d9925d0)）
- 提问卡片采用更紧凑的布局，回答支持 Enter 提交、Shift+Enter 换行，提交失败时保留已填内容并提供重试。（[b6685f8](https://github.com/hjd-hitsz/claudex-web/commit/b6685f8)）
- 修复批注输入在单行换行边界反复切换布局、导致整页显示错误的问题。（[53a0d3d](https://github.com/hjd-hitsz/claudex-web/commit/53a0d3d)）
