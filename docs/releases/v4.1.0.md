- 对话 token 用量按后端与对话独立保存，重新打开、刷新及服务重启后恢复；已有对话自动补齐可读取的统计，分支继承对应历史位置的用量。（[0233f3e](https://github.com/hjd-hitsz/claudex-web/commit/0233f3e)）
